# 提示词结构指南

## 核心原则

- **风格从需求读取**：美术风格、素材类型由角色需求.md决定
- **透明背景**：便于后续使用
- **无环境**：纯角色设计图

## 素材类型模板

### 立绘（对话用）

```
[主体描述]，[姿势描述]，全身立绘，[风格]，游戏角色立绘，透明背景，高质量
```

**适用场景**：剧情对话、角色选择界面、菜单展示

### 战斗形象（俯视角）

```
[主体描述]，[姿势描述]，角色多方向视图，正面视图、背面视图并排展示，俯视角角色设计图，[风格]，游戏战斗角色，透明背景，高质量
```

**适用场景**：俯视角战斗场景中的角色显示

### 头像（UI用）

```
[面部描述]，[表情]，角色头像，[风格]，游戏角色头像，透明背景，高质量
```

**适用场景**：对话框、状态栏、队伍界面

## 通用负面提示词

```
低质量，模糊，变形，畸形，比例失调，水印，签名，文字，背景，环境，场景
```

## 风格读取示例

从角色需求.md中可能读取到的风格描述：

| 需求描述 | 对应提示词风格 |
|---------|---------------|
| "日系游戏原画风格" | anime game art style, Japanese game illustration |
| "手绘风格" | hand-drawn style, traditional art |
| "像素风格" | pixel art style, retro game aesthetic |
| "油画风格" | oil painting style, painterly |
| "Q版风格" | chibi style, cute, simplified |
| "写实风格" | realistic style, detailed rendering |

**重要**：风格关键词应直接从需求文档提取，不做假设。
