# 游戏需求分析

从世界观和设定集文档中提取并生成结构化的游戏开发需求。

## 输入

| 文件 | 必需 | 说明 |
|-----|-----|-----|
| 世界观.md | 是 | 游戏世界的基础设定 |
| 设定集.md | 否 | 详细的游戏设定补充 |

## 输出

生成以下5个文档到指定目录：

1. **游戏基本信息.md** - 游戏概述、类型、平台、技术栈
2. **角色需求.md** - 角色列表、外观描述、动画需求
3. **场景需求.md** - 场景列表、环境描述、交互元素
4. **音频需求.md** - BGM列表、音效需求、风格参考
5. **代码需求.md** - 核心系统、功能模块、技术要点

## 工作流程

1. 读取世界观.md和设定集.md
2. 分析提取关键信息（见 [references/extraction-guide.md](references/extraction-guide.md)）
3. 按模板格式生成5个输出文档（见 [references/output-templates.md](references/output-templates.md)）
4. 确认输出文件已正确生成

## 调用方式

```
使用 game-requirement-analysis skill
输入目录: <包含世界观.md的目录>
输出目录: <需求文档输出目录>
游戏引擎: <Unity/Godot/Ren'Py/自研等>
游戏类型: <RPG/视觉小说/冒险/动作等>
```
