## 角色: 罗兰

### 基本信息
- **ID**: char_001
- **名称**: 罗兰
- **类型**: 主角
- **性别**: 男
- **年龄**: 19岁
- **阵营**: 骑士团（科技阵营）
- **重要性**: 核心

### 外观描述
少年体型，轻型外骨骼装备。黑白灰配色服装，参考条顿骑士团风格。

### 背景故事
5岁时双亲被薇误杀，仅存片段记忆。被骑士团成员康拉德救下并抚养长大。

### 性格特点
- 复仇心切但内心善良
- 对康拉德有深厚的感激和依赖
- 在正义与复仇之间挣扎

### 出现场景
- 骑士团城镇（安全区）
- 废土
- 城市废墟
- 副本

### 动画需求
- [ ] 待机动画
- [ ] 移动动画
- [ ] 攻击动画（近战）
- [ ] 受击动画
- [ ] 死亡动画

### 表情需求（对话立绘）
- 平静
- 微笑
- 大笑
- 愤怒
- 暴怒
- 沮丧
- 思索
- 冷漠

### 特殊需求
- 外骨骼装备需要有机械感的表现
- 战斗特效需要体现科技感

| 用途 | 角色基础设计，立绘和精灵图的参考基准 |

| 属性 | 描述 |
|------|------|
| 用途 | 对话系统 |
| 尺寸 | 400×800px |
| 格式 | PNG，透明背景 |

**必需表情**：平静、微笑、大笑、愤怒、暴怒、沮丧、思索、冷漠

| 属性 | 描述 |
|------|------|
| 用途 | 游戏内角色动画 |
| 风格 | Q版（2-3头身） |
| 格式 | PNG，透明背景 |
