## 场景: 大地图

### 基本信息
- **ID**: scene_map
- **名称**: 大地图
- **类型**: 导航界面
- **重要性**: 核心

- **功能**: 全局导航界面，以图标/节点展示世界各区域
- **交互**: 玩家点对点选择目的地后进入对应场景

- **ID**: scene_001
- **名称**: 7号农场

- **场景分类**: 农田/废墟
- **重要性**: 核心
- **地图尺寸**: 1024×1024（入口房）

### 环境描述
- **时间**: 白天
- **天气**: 晴朗/微阴

#### 4. 遮罩层 (Overlay Layer)

## 通用战斗场景房间模板

战斗场景内部采用多房间推进结构，不同房间类型有不同的设计要求：

| 房间类型 | 尺寸建议 | 特点 |
|---------|---------|------|
| 入口房 | 1024×1024 | 安全，有补给，无刷怪 |
| 普通房 | 1024×1024 | 随机地形+刷怪点，清空后开门 |
| 精英房 | 1536×1536 | 较大空间，1只精英怪 |
| Boss房 | 2048×2048 | 开阔场地，可能有机关 |
| 隐藏房 | 768×768 | 宝箱或隐藏Boss，需特殊条件 |

### 房间推进结构
```
入口 → [普通房] → [普通房] → [精英房] → [普通房] → [Boss房] → 通关
                      ↓
                 [隐藏房]（可选，需特殊条件触发）
```

### 隐藏房触发条件示例
- 无伤通关前几房间
- 携带特定物品
- 特定角色路线
