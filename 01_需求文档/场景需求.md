## 场景: 废土区域·战斗场景

### 基本信息
- **ID**: scene_002
- **名称**: 废土区域·战斗场景
- **类型**: 战斗场景（多房间推进结构）
- **场景分类**: 废土
- **重要性**: 核心
- **地图尺寸**: 多房间，每房间 1024×1024 ~ 2048×2048

### 环境描述
- **时间**: 白天 / 黄昏
- **天气**: 晴朗 / 阴天 / 灰烬
- **氛围**: 荒凉、危险、干燥

### 地图图层结构（俯视角游戏）

#### 1. 地面层 (Ground Layer)
- **主纹理**: 干裂土地、沙地、碎石地面
- **边缘过渡**: 沙地与石地的过渡
- **Tile规格**: 128×128

#### 2. 装饰层 (Decoration Layer)
- **地面装饰**: 裂缝、弹坑、枯草、风化痕迹
- **环境装饰**: 残破路标、生锈铁丝网、废弃车辆残骸、干枯灌木

#### 3. 碰撞层 (Collision Layer)
| 物体名 | 类型 | 碰撞形状 | 尺寸 |
|-------|------|---------|------|
| 废弃建筑残骸 | 阻挡 | 矩形/多边形 | 大 |
| 巨型岩石 | 阻挡 | 多边形 | 中 |
| 铁丝网围栏 | 阻挡 | 矩形 | 中 |
| 废弃车辆 | 阻挡 | 矩形 | 中 |

#### 4. 遮罩层 (Overlay Layer)
- **遮罩物体**: 废弃建筑屋檐、桥梁残骸

### 房间结构

| 房间类型 | 尺寸建议 | 刷怪配置 |
|---------|---------|---------|
| 入口房 | 1024×1024 | 安全，有补给箱 |
| 普通房 | 1024×1024 | 辐射巨鼠、钢鬃野猪 3-5只 |
| 精英房 | 1536×1536 | 裂变熊 / 双头狼 |
| Boss房 | 2048×2048 | 区域Boss |
| 隐藏房 | 768×768 | 宝箱 / 隐藏Boss |

### 摆件需求

| 素材名 | 类型 | 尺寸范围 | 说明 |
|-------|------|---------|------|
| 地面Tile | 基础 | 128×128 / 256×256 | 干裂土地、沙地、碎石 |
| 墙体 | 碰撞 | 按需 | 废弃混凝土墙、铁皮墙 |
| 废弃车辆 | 碰撞/装饰 | 256×256 ~ 512×512 | 不同损坏程度 |
| 路标残骸 | 装饰 | 64×64 ~ 128×128 | 生锈变形 |
| 补给箱 | 交互 | 64×64 ~ 128×128 | 可开启 |
| 枯灌木 | 装饰 | 64×64 ~ 128×128 | 干枯状态 |

### 光照与特效
- **主光源**: 暗黄色日光，低角度
- **环境光**: 暖黄色调，偏暗
- **动态光效**: 远处闪电、火堆
- **粒子特效**: 飘沙、灰尘

### 场景连接
- ← 大地图 (入口)
- → 下一战斗场景 / Boss通关后返回大地图

## 过场图片需求

过场为按顺序自动播放的静态图片序列，穿插在场景之间用于叙事。

| 属性 | 规格 |
|------|------|
| 图片尺寸 | 1920×1080px |
| 格式 | PNG |
| 风格 | 油画 |
| 触发时机 | 进入场景前 / 场景内对话中 / 离开场景后 |

过场具体画面根据剧本分镜确定。
