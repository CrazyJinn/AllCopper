## UI: 游戏HUD

### 基本信息
- **ID**: ui_001
- **名称**: 游戏HUD
- **类型**: 战斗UI
- **优先级**: P0

### 界面布局
```
┌─────────────────────────────────────────────────────────────────┐
│ [HP条] [护盾条]                                    [小地图]    │
│ [子弹/读条]                                      (Tab切换)   │
│                                                                 │
│                                                                 │
│                                                                 │
│                        游戏画面区域                              │
│                                                                 │
│                                                                 │
│                                                                 │
│                                                                 │
│ [快捷栏: 1][2][3][4]                        [技能: Q][E][R]     │
│ [货币: 电池数量]                            [终极技能: 右键]    │
└─────────────────────────────────────────────────────────────────┘
```

### 元素清单
| 元素名 | 类型 | 位置 | 尺寸 | 说明 |
|-------|------|------|------|------|
| HP条 | 进度条 | 左上 | 200×20 | 红色，显示当前生命值 |
| 护盾条 | 进度条 | 左上(HP条上方) | 200×15 | 蓝色/灰色，显示护盾值 |
| 子弹/读条 | 进度条 | HP条下方 | 150×15 | 科技阵营显示子弹数，魔法阵营施法时显示读条进度 |
| 小地图 | 圆形/方形 | 右上 | 150×150 | 按Tab切换大小/隐藏 |
| 快捷栏 | 物品槽 | 左下 | 4×50×50 | 4个消耗品槽位 |
| 技能栏 | 图标按钮 | 右下 | 3×50×50 | Q、E、R技能图标+CD遮罩 |
| 终极技能 | 图标按钮 | 右下 | 60×60 | 右键技能，较大图标 |
| 货币显示 | 文本+图标 | 左下(快捷栏旁) | 100×30 | 电池图标+数字 |

### 交互逻辑
- **显示条件**: 游戏进行时始终显示（对话/过场时隐藏部分元素）
- **快捷栏**: 数字键1-4使用对应槽位物品
- **技能**: Q、E、R施放对应技能，右键施放终极技能
- **小地图**: Tab键切换显示模式（小/大/隐藏）

### 美术需求
- **风格**: 废土/机械风格，金属质感边框
- **主色调**: 暗色背景，白色/橙色高亮
- **动画需求**: HP/护盾变化时平滑过渡，技能CD旋转遮罩

### 角色站位规则
| 阵营 | 位置 |
|------|------|
| 科技派 | 屏幕左侧 |
| 魔法派 | 屏幕右侧 |

### 表情立绘系统
| 表情 | 用途 |
|------|------|
| 平静 | 普通对话 |
| 微笑 | 积极情绪 |
| 大笑 | 开心、兴奋 |
| 愤怒 | 不满、生气 |
| 暴怒 | 极度愤怒 |
| 沮丧 | 低落情绪 |
| 思索 | 思考、犹豫 |
| 冷漠 | 无情、冷淡 |

### 美术需求
- **立绘规格**: 400×800px，PNG格式，纯白背景
- **对话框**: 半透明暗色背景，金属/废土风格边框
- **动画需求**: 打字机效果，立绘淡入淡出，表情切换过渡

│  │         占用不同格子            │  │  物品描述             ││

│  容量: XX/YY            [排序] [筛选▼]                          │

### 元素清单
| 元素名 | 类型 | 位置 | 尺寸 | 说明 |
|-------|------|------|------|------|
| 物品网格 | 网格容器 | 左侧 | 400×400 | 类似暗黑2，物品占用不同格子数 |
| 物品详情 | 面板 | 右侧 | 250×400 | 显示选中物品信息 |
| 物品图标 | 图片 | 详情区 | 64×64 | 物品图标 |
| 物品名称 | 文本 | 详情区 | - | 物品名称 |
| 物品描述 | 文本 | 详情区 | - | 物品描述/属性 |
| 使用按钮 | 按钮 | 详情区 | 80×30 | 使用物品 |
| 丢弃按钮 | 按钮 | 详情区 | 80×30 | 丢弃物品 |
| 容量显示 | 文本 | 底部 | - | 当前容量/最大容量 |
| 排序按钮 | 按钮 | 底部 | 60×30 | 自动整理背包 |
| 筛选下拉 | 下拉框 | 底部 | 100×30 | 按类型筛选物品 |

### 交互逻辑
- **打开条件**: 按I或B键
- **关闭条件**: 按Esc或再次按I/B
- **拖拽**: 物品可拖拽移动位置
- **双击**: 使用物品
- **右键**: 显示快捷菜单（使用/丢弃）

### 背包容量系统
- 每个角色有固定的背包大小（格子数）
- 每个物品占用一定的空间大小（1×1, 1×2, 2×2等）
- 穿机甲角色天生背包容量更大

## UI: 过场动画播放器

### 基本信息
- **ID**: ui_014
- **名称**: 过场动画播放器
- **类型**: 功能UI
- **优先级**: P2

### 规格要求
- **分辨率**: 1920×1080 或 1280×720
- **帧率**: 30/60 FPS
- **格式**: MP4 或静态图序列

### 触发时机
| 时机 | 行为 |
|------|------|
| 对话前 | 先播放过场 |
| 对话中 | 暂停对话→播放过场→继续对话 |
| 对话后 | 对话结束后播放 |

### 控制按钮
- 跳过按钮（右下角，3秒后显示）
- 暂停/继续按钮
