## UI: 游戏HUD

### 基本信息
- **ID**: ui_001
- **名称**: 游戏HUD
- **类型**: 战斗UI
- **优先级**: P0

### 界面布局
```
┌─────────────────────────────────────────────────────────────┐
│ ┌──────┐                                      ┌──────────┐  │
│ │ 电池 │                                      │ 小地图   │  │
│ │ x99  │                                      │ (可选)   │  │
│ └──────┘                                      └──────────┘  │
│                                                             │
│                                                            □ │
│                        战斗区域                             □ │
│                                                            □ │
│                         (俯视角)                            □ │
│                                                            □ │
│                                                             │
│ ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐         │
│ │  血条   │  │  魔法值 │  │ 技能栏  │  │ 终极技  │         │
│ │  ████   │  │  ████   │  │ [Q][E]  │  │  [R]    │         │
│ └─────────┘  └─────────┘  └─────────┘  └─────────┘         │
└─────────────────────────────────────────────────────────────┘
```

### 元素清单
| 元素名 | 类型 | 位置 | 尺寸 | 说明 |
|-------|------|------|------|------|
| 血条 | 进度条 | 左下 | 200×20 | 玩家当前生命值 |
| 魔法值 | 进度条 | 左下 | 200×20 | 玩家魔法/能量值 |
| 电池显示 | 文本+图标 | 左上 | 80×30 | 纽扣电池货币 |
| 技能栏-技能1 | 图标+冷却 | 下中 | 50×50 | Q键技能 |
| 技能栏-技能2 | 图标+冷却 | 下中 | 50×50 | E键技能 |
| 终极技能 | 图标+冷却 | 下中 | 60×60 | 右键技能，R键换弹/冥想 |
| 小地图 | 圆形/方形 | 右上 | 150×150 | 可选功能 |
| 快捷键提示 | 文本 | 技能下方 | - | 显示对应按键 |

### 交互逻辑
- **显示条件**: 游戏进行中始终显示（可设置隐藏）
- **技能冷却**: 图标变暗+倒计时数字+冷却动画
- **血量变化**: 平滑过渡动画，低于30%红色闪烁警告

### 美术需求
- **风格**: 与油画风格协调，半透明背景
- **主色调**: 根据阵营配色（科技/魔法）
- **动画需求**: 血条平滑变化、技能冷却旋转动画
