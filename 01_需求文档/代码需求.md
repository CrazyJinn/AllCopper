# 代码需求

## 技术概述
- **游戏引擎**: Godot
- **开发语言**: GDScript
- **目标分辨率**: 1920×1080
- **帧率目标**: 60fps

## 核心系统

### 1. 角色控制系统
**优先级**: P0
**描述**: 控制玩家角色的移动、闪避、基本交互

**功能点**:
- 8方向移动（WASD）
- 翻滚闪避（空格键），闪避期间无敌
- 面向鼠标方向（攻击朝向）
- 移动状态机（待机/行走/奔跑/闪避）

**技术要点**:
- 使用CharacterBody2D
- 状态机模式管理角色状态
- 闪避无敌帧实现

---

### 2. 战斗系统
**优先级**: P0
**描述**: 处理角色和怪物的战斗逻辑

**功能点**:
- 普通攻击（左键）：科技即时射击，魔法按住读条施法
- 终极技能（右键）
- 技能1/2（Q/E）
- 换弹/加快CD（R）
- 伤害计算与分配（HP/护盾）
- 伤害类型（普通/中毒/碎盾）
- 伤害数字显示

**技术要点**:
- 攻击判定系统（碰撞检测）
- 伤害分配公式：X%护盾 / (100-X)%HP
- 护盾自动恢复机制
- 技能CD系统
- 对象池管理伤害数字

**阵营差异**:
| 阵营 | 特点 |
|------|------|
| 科技 | 远程枪械攻击，需要子弹管理，换弹机制 |
| 魔法 | 远程魔法攻击，释放时需要站定读条 |

---

### 3. 对话系统
**优先级**: P0
**描述**: 处理角色对话、剧情展示

**功能点**:
- 两种布局模式（对话/独白）
- 打字机效果
- 表情立绘切换
- 选项分支
- 过场动画触发
- 角色站位规则（科技左/魔法右）

**技术要点**:
- 对话数据结构（JSON/Resource）
- 立绘动态加载
- 打字机协程/定时器实现
- 过场动画播放器集成

---

### 4. 背包系统
**优先级**: P0
**描述**: 类似暗黑2的背包容量系统

**功能点**:
- 物品网格管理
- 物品大小占用（1×1, 1×2, 2×2等）
- 容量检测
- 拖拽移动
- 物品使用/装备/丢弃
- 排序/筛选

**技术要点**:
- 二维数组管理背包格子
- 物品放置算法（检测是否有足够连续空间）
- 机甲角色背包加成

---

### 5. 场景管理系统
**优先级**: P0
**描述**: 管理游戏场景的加载、切换、过渡

**功能点**:
- 场景切换
- 过渡动画（淡入淡出）
- 副本房间流程管理
- 场景数据持久化

**技术要点**:
- 场景预加载
- 异步加载
- 场景状态保存

---

### 6. 怪物AI系统
**优先级**: P0
**描述**: 控制怪物的行为逻辑

**功能点**:
- 巡逻行为
- 追击玩家
- 攻击行为
- 特殊技能（按怪物类型）
- 仇恨系统

**技术要点**:
- 行为树/状态机
- 寻路算法（Navigation2D）
- 怪物数据配置

**怪物特殊行为**:
| 怪物 | 特殊行为 |
|------|---------|
| 辐射巨鼠 | 群体攻击 |
| 钢鬃野猪 | 冲撞攻击 |
| 骨翼鸦 | 空中俯冲 |
| 裂变熊 | 25%血量以下狂暴 |
| 双头狼 | 协同攻击 |
| 藤蔓怪 | 群体缠绕 |

## 数据结构需求

### 角色数据
```gdscript
# 角色基础数据结构
class_name CharacterData

var id: String
var name: String
var type: String  # protagonist/npc/enemy
var faction: String  # tech/magic

# 属性
var max_hp: int
var current_hp: int
var max_shield: int
var current_shield: int
var attack: int
var defense: int
var move_speed: float
var shield_absorb_rate: float  # 护盾吸收率

# 资源
var max_bullets: int  # 科技阵营
var current_bullets: int
var cast_time: float  # 魔法阵营：施法读条时间

# 背包容量
var inventory_size: Vector2i  # 格子数
```

### 物品数据
```gdscript
# 物品数据结构
class_name ItemData

var id: String
var name: String
var type: String  # weapon/armor/consumable/material
var size: Vector2i  # 占用格子数
var stackable: bool
var max_stack: int
var description: String
var icon: Texture2D
```

### 怪物数据
```gdscript
# 怪物数据结构
class_name MonsterData

var id: String
var name: String
var type: String  # normal/elite/boss
var category: String  # animal/plant

# 属性
var max_hp: int
var attack: int
var defense: int
var move_speed: float

# 特殊能力
var abilities: Array[String]

# 掉落
var drop_table: Array

# 行为配置
var behavior_config: Dictionary
```

### 对话数据
```gdscript
# 对话数据结构
class_name DialogueData

var id: String
var speaker_id: String
var speaker_name: String
var text: String
var expression: String  # 表情立绘

# 可选
var choices: Array[Dictionary]  # 选项分支
var next_dialogue_id: String

# 特殊触发
var cutscene_id: String  # 过场动画
var event_trigger: String  # 事件触发
```

### 场景数据
```gdscript
# 场景数据结构
class_name SceneData

var id: String
var name: String
var type: String  # overworld/dungeon_room/ui_background
var category: String  # town/wasteland/forest/ruins/snow/indoor

# 地图信息
var map_size: Vector2i
var tile_size: int

# 功能区域
var spawn_points: Array[Dictionary]
var interact_points: Array[Dictionary]
var special_areas: Array[Dictionary]

# 连接
var connections: Array[String]  # 可通往的场景ID
```

## 性能要求

### 帧率
- **目标帧率**: 60fps
- **最低帧率**: 30fps

### 场景复杂度
- **同屏怪物数**: ≤20
- **同屏特效数**: ≤50
- **UI层级**: ≤10层

### 内存管理
- 对象池复用伤害数字、特效
- 场景资源预加载
- 不活跃资源卸载

### 加载时间
- **场景切换**: ≤2秒
- **首次加载**: ≤5秒
