### 2. 战斗系统
**优先级**: P0
**状态**: 已实现核心模块
**描述**: 核心战斗机制，支持近战/远程/魔法

**功能点**:
- 左键普通攻击/射击
- 右键终极技能
- Q 技能1
- E 技能2
- R 换弹/冥想（法师恢复魔法）
- 伤害计算与显示（大数字）
- 暴击系统
- buff/debuff 系统

**技术要点**:
- 攻击判定（碰撞检测/射线检测）
- 技能冷却系统
- 伤害数字飘字效果
- 击退/硬直效果
- 多种伤害类型（物理/魔法/辐射/毒素）

**伤害计算规则**:
```
普通伤害分配：
├── shieldAbsorbRate% → 扣除护盾（动态属性，默认90%）
└── (1 - shieldAbsorbRate)% → 扣除HP（默认10%）

特殊伤害类型：
├── 中毒伤害：直接扣除HP，无视护盾
└── 碎盾伤害：扣除巨额护盾（2倍），不扣HP

护盾恢复：
├── 未受伤害时自动恢复
└── 恢复速率由 shieldRegenRate 决定

防御减伤公式：
├── reduction = defense / (defense + 100)
└── 最大减伤率：80%
```

**已实现模块**:
- `DamageCalculator` - 伤害计算器（含防御减伤、伤害类型）
- `BuffSystem` - Buff/Debuff系统（含DOT/HOT、状态效果）
- `CombatSystem` - 战斗系统协调器
- `AttackEntity` - 攻击实体基类
- `Projectile` - 投射物系统（远程攻击）
- `MeleeHitbox` - 近战攻击判定框

**受伤判定**:
- 角色：碰撞怪物身体 / 碰撞怪物攻击
- 怪物：碰撞角色攻击
- 闪避无敌：翻滚期间免疫所有伤害

## 数据结构需求

### 角色数据
```typescript
interface CharacterData {
  id: string;           // 角色ID
  name: string;         // 角色名称
  type: 'player' | 'npc' | 'enemy';
  faction: 'tech' | 'magic' | 'wild';

  // 属性
  stats: {
    hp: number;
    maxHp: number;
    shield: number;      // 护盾值
    maxShield: number;   // 最大护盾值
    shieldRegenRate: number; // 护盾恢复速率（每秒）
    shieldAbsorbRate: number; // 护盾伤害吸收率（0-1，如0.9表示90%伤害由护盾吸收）
    mp: number;
    maxMp: number;
    attack: number;
    defense: number;
    speed: number;
  };

  // 战斗资源
  combat: {
    ammo: number;        // 当前子弹数（科技阵营）
    maxAmmo: number;     // 最大子弹数
    skillCooldown: number;   // 技能CD（秒）
    attackCooldown: number;  // 普攻CD（秒）
  };

  // 背包
  inventory: {
    maxSize: number;     // 背包容量（格子数）
    hasMechaBonus: boolean; // 是否有机甲背包加成
  };

  // 战斗相关
  skills: string[];     // 技能ID列表
  equipment: string[];  // 装备ID列表

  // 动画资源（简化后）
  animations: {
    idle: string;       // 待机
    walk: string;       // 移动
    attack: string;     // 攻击
    hurt: string;       // 受击
    death: string;      // 死亡
  };

  // 对话立绘表情（8种）
  portraits: {
    calm: string;       // 平静
    smile: string;      // 微笑
    laugh: string;      // 大笑
    angry: string;      // 愤怒
    furious: string;    // 暴怒
    depressed: string;  // 沮丧
    thinking: string;   // 思索
    cold: string;       // 冷漠
  };
}
```

interface MonsterData {

  category: 'animal' | 'plant';

  // 属性

    shield: number;
    maxShield: number;
    shieldRegenRate: number;
    shieldAbsorbRate: number;
    attack: number;
    defense: number;
    speed: number;
  };

  // 战斗资源
  combat: {
    skillCooldown: number;
    attackCooldown: number;
  };

  // 能力
  abilities: {
    id: string;
    type: 'melee' | 'ranged' | 'aoe' | 'special' | 'poison' | 'shield_break';
    damage: number;
    cooldown: number;
    damageType: 'normal' | 'poison' | 'shield_break';
  }[];

  // 特殊状态
  special?: {

  };

  // 掉落
  drops: {
    itemId: string;
    chance: number;
    amount: [number, number];
  }[];

  // AI配置
  aiConfig: {
    aggroRange: number;
    attackRange: number;
    patrolRadius: number;

  // 动画资源（简化后）
  animations: {
    idle: string;
    walk: string;
    attack: string;
    hurt: string;
    death: string;
  };
}

## 性能要求

### 帧率目标
- **目标帧率**: 60fps
- **最低帧率**: 30fps

### 资源加载
- **首屏加载**: < 3秒
- **场景切换**: < 2秒
- **资源预加载**: 后台异步加载

### 内存管理
- **内存占用**: < 500MB
- **资源释放**: 场景切换时释放未使用资源
- **对象池**: 常用对象复用（子弹、特效、伤害数字）

### 优化要点
- 使用图集减少DrawCall
- 合理使用对象池
- 避免频繁GC
- 精灵合批渲染
- 减少实时阴影计算
