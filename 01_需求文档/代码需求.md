# 代码需求

## 技术概述
- **游戏引擎**: Godot
- **开发语言**: GDScript
- **目标分辨率**: 1920×1080
- **帧率目标**: 60fps
- **视角**: 2D 俯视角

---

## 核心系统

### 1. 角色控制系统
**优先级**: P0
**描述**: 2D俯视角角色移动、闪避、攻击控制
**功能点**:
- WASD八方向移动
- 空格翻滚闪避（无敌帧）
- 左键攻击（科技：普攻 / 魔法：按住读条施法）
- 右键终极技能
- Q/E 技能1/2
- R 换弹/加快CD
- F 拾取物品
- 1-4 快捷栏使用
- 鼠标指向即为目标

**技术要点**:
- 移动使用 velocity + move_and_slide
- 闪避无敌帧通过 collision layer 切换实现
- 精灵方向：正面/背面两套，左右翻转

---

### 2. 战斗系统
**优先级**: P0
**描述**: HP/护盾双资源战斗，多种伤害类型，阵营差异化战斗

**功能点**:
- HP系统（归零即死亡）
- 护盾系统（优先吸收伤害，缓慢自动恢复）
- 动态伤害分配（护盾吸收率由角色属性决定）
- 伤害类型：普通伤害、中毒伤害（直接扣HP无视护盾）、碎盾伤害
- 普攻CD和终极技能CD
- 科技阵营：子弹资源（远程武器弹药）
- 魔法阵营：按住读条施法机制

**技术要点**:
- 碰撞检测判定攻击命中
- 伤害计算公式需支持护盾吸收率动态配置
- DOT（持续伤害）用于中毒效果

---

### 3. 敌人AI系统
**优先级**: P0
**描述**: 怪物行为控制，包含普通怪和精英怪的不同AI模式

**功能点**:
- 普通怪物AI：巡逻→发现玩家→追击→攻击
- 精英怪物AI：特殊技能使用、状态切换（如裂变熊25%血量狂暴）
- Boss AI：多阶段行为模式
- 远程怪物AI：保持距离+远程攻击
- 飞行怪物AI：空中移动+俯冲攻击

**技术要点**:
- 行为树或状态机模式
- 精英怪特殊机制（双头狼双头独立攻击、树人守卫护甲格挡）

---

### 4. 对话系统
**优先级**: P0
**描述**: 双模式对话界面，支持立绘切换和过场动画

**功能点**:
- 对话布局模式：角色分列两边（科技派左侧/魔法派右侧）
- 独白布局模式：角色居中
- 表情立绘系统：8种表情切换（平静/微笑/大笑/愤怒/暴怒/沮丧/思索/冷漠）
- 过场动画插入：对话前/中/后可触发图片轮播
- 立绘规格：400×800px
- 文本框高度：约200px
- 点击继续推进对话

**技术要点**:
- 对话数据以 JSON 格式存储
- 过场动画图片序列：1920×1080 PNG
- 立绘淡入淡出动画

---

### 5. 背包系统
**优先级**: P0
**描述**: 类似暗黑2的网格背包容量系统

**功能点**:
- 固定背包大小（网格系统）
- 每个物品占用固定空间
- 物品放入需检查容量
- 拖拽排列物品
- 机甲角色背包容量加成
- 快捷栏配置（拖拽消耗品到1-4位）

**技术要点**:
- 网格碰撞检测算法
- 物品数据结构需包含尺寸信息

---

### 6. 副本系统
**优先级**: P0
**描述**: 副本房间流程管理和生成

**功能点**:
- 房间流程：入口→普通房→精英房→Boss房
- 隐藏房触发条件（如无伤通关）
- 房间清空后开启下一房间门
- Boss击杀后副本通关
- 摆件拆分生成：分析→提示词→图片→引擎组合

**房间类型**:
| 类型 | 尺寸 | 说明 |
|-----|------|------|
| 入口房 | 1024×1024 | 安全补给 |
| 普通房 | 1024×1024 | 随机地形+刷怪 |
| 精英房 | 1536×1536 | 精英怪+必掉稀有 |
| Boss房 | 2048×2048 | Boss战 |
| 隐藏房 | 768×768 | 宝箱/隐藏Boss |

---

### 7. 关卡类型系统
**优先级**: P1
**描述**: 多种关卡类型，各有不同核心玩法

**功能点**:
- 教学关卡：逐步解锁功能
- 防守关卡：波次防守，大量敌人
- 潜入关卡：视角受限，警戒系统
- 收集关卡：击杀收集资源
- 解谜关卡：解谜元素，偏女主路线
- 对话关卡：纯对话推进
- 过场动画关卡：自动播放

---

### 8. 经济系统
**优先级**: P0
**描述**: 纽扣电池货币体系

**功能点**:
- 通用货币：纽扣电池（满电=1单位）
- 获得途径：完成任务、击杀人形敌人、怪物精粹兑换
- 消耗途径：购买物品/装备/服务
- 商店NPC交易界面

## 数据结构需求

### 角色数据
- HP、护盾值及恢复速率
- 护盾吸收率（动态伤害分配比例）
- 攻击力、防御力
- 技能列表及CD配置
- 背包容量

### 物品数据
- 物品ID、名称、描述
- 物品类型（装备/消耗品/材料）
- 物品尺寸（背包网格占用）
- 物品效果
- 稀有度

### 怪物数据
- HP、护盾值
- AI行为配置
- 掉落表
- 特殊能力配置
- 精英怪触发条件

### 对话数据
- 对话节点ID
- 说话者、表情、文本
- 分支选项
- 过场动画触发
- 条件判断

## 阵营差异

| 维度 | 科技阵营 | 魔法阵营 |
|------|---------|---------|
| 核心玩法 | 搜打撤循环 | 过剧情，角色成长 |
| 战斗方式 | 枪械远程/外骨骼近战 | 魔法施放，大数字秒杀 |
| 左键操作 | 普通攻击 | 按住读条施法 |
| R键功能 | 换弹 | 加快技能CD |
| 子弹资源 | 有 | 无 |
| 背包加成 | 机甲角色更大 | 标准 |
