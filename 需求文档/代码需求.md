# 代码需求

## 技术概述
- **游戏引擎**: Cocos
- **开发语言**: TypeScript / JavaScript
- **目标分辨率**: 1920x1080（支持16:9）
- **帧率目标**: 60fps

## 核心系统

### 1. 角色控制系统
**优先级**: P0
**描述**: 玩家角色的移动和操作控制
**功能点**:
- WASD移动控制
- 鼠标瞄准系统
- 翻滚闪避（空格，带无敌帧）
- 左键普通攻击
- 右键终极技能
- Q/E技能1/2
- R换弹/冥想恢复
- F拾取物品
**技术要点**:
- 俯视角2D移动
- 输入缓冲系统
- 无敌帧实现

### 2. 战斗系统
**优先级**: P0
**描述**: 核心战斗机制
**功能点**:
- 近战攻击（科技主角）
- 远程魔法攻击（魔法主角）
- 技能系统（Q/E/R/右键）
- 伤害计算
- 击退效果
- 暴击系统
**技术要点**:
- 碰撞检测
- 伤害数字显示
- 攻击范围可视化

### 3. 副本/房间系统
**优先级**: P0
**描述**: 副本房间生成和流程控制
**功能点**:
- 房间链式结构（入口→普通→精英→Boss）
- 清怪开门机制
- 隐藏房触发条件
- 房间传送门
- 副本通关结算
**技术要点**:
- 房间模板系统
- 动态怪物生成
- 房间状态管理

### 4. 怪物AI系统
**优先级**: P0
**描述**: 各类怪物的行为逻辑
**功能点**:
- 基础AI（巡逻、追击、攻击）
- 远程攻击AI（毒液、酸液、魔法）
- 精英怪特殊行为（狂暴、双头协同）
- Boss AI（多阶段、特殊技能）
**技术要点**:
- 状态机AI
- 寻路系统
- 技能释放逻辑

### 5. 物品/背包系统
**优先级**: P1
**描述**: 物品收集和管理
**功能点**:
- 物品拾取
- 背包界面
- 物品堆叠
- 物品分类（装备/消耗品/材料）
- 物品详情
**技术要点**:
- 物品数据结构
- 背包容量管理

### 6. 经济系统
**优先级**: P1
**描述**: 货币和交易
**功能点**:
- 子弹货币系统
- 怪物精粹兑换
- 商店界面
- 购买/出售物品
**技术要点**:
- 货币显示
- 交易逻辑

### 7. 角色成长系统
**优先级**: P1
**描述**: 角色强化和升级
**功能点**:
- 等级系统
- 属性提升
- 技能解锁
- 装备强化
**技术要点**:
- 属性计算
- 技能树/解锁逻辑

### 8. 任务系统
**优先级**: P1
**描述**: 任务接取和追踪
**功能点**:
- 任务接取
- 任务目标追踪
- 任务完成判定
- 任务奖励
**技术要点**:
- 任务数据结构
- 条件检测

## 数据结构需求

### 角色数据
```typescript
interface Character {
  id: string;
  name: string;
  type: 'player' | 'npc' | 'enemy';
  faction: 'tech' | 'magic' | 'neutral';
  stats: {
    hp: number;
    maxHp: number;
    mp?: number;
    maxMp?: number;
    attack: number;
    defense: number;
    speed: number;
  };
  position: { x: number; y: number };
  // ...
}
```

### 物品数据
```typescript
interface Item {
  id: string;
  name: string;
  type: 'weapon' | 'armor' | 'consumable' | 'material';
  rarity: 'common' | 'rare' | 'epic' | 'legendary';
  stackable: boolean;
  maxStack: number;
  // ...
}
```

### 副本数据
```typescript
interface Dungeon {
  id: string;
  name: string;
  rooms: Room[];
  currentRoomIndex: number;
  // ...
}

interface Room {
  type: 'entrance' | 'normal' | 'elite' | 'boss' | 'hidden';
  enemies: EnemySpawn[];
  cleared: boolean;
  // ...
}
```

## 性能要求
- 保持60fps稳定帧率
- 同屏怪物数量优化（建议<50）
- 对象池管理（子弹、特效）
- 资源异步加载
