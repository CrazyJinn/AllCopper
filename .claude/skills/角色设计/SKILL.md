# 角色设计提示词生成

将角色需求转化为专业的AI绘图提示词。

## 输入

| 文件 | 必需 | 说明 |
|-----|-----|-----|
| 游戏基本信息.md | 是 | 提供美术风格、世界观背景 |
| 角色需求.md | 是 | 角色外观、性格、阵营、素材类型需求 |

## 输出

生成3个文件到指定目录：

```
输出目录/
├── 主角.md
├── NPC.md
└── 怪物.md
```

## 素材类型

根据角色需求.md中的描述，为每个角色生成对应的素材类型：

| 素材类型 | 用途 | 说明 |
|---------|------|------|
| 立绘 | 对话、剧情、菜单展示 | 全身像，精美风格 |
| 战斗形象 | 俯视角战斗场景 | 小型化，多方向视图 |
| 头像 | UI、对话框、状态栏 | 头部特写 |

**注意**：具体需要哪些素材类型、使用什么风格，由角色需求.md中的描述决定，不在此硬编码。

## 工作流程

1. 读取游戏基本信息.md，提取世界观背景
2. 读取角色需求.md，提取角色信息和素材需求
3. 根据需求为每个角色生成对应素材的提示词
4. 输出3个合并文件

## 调用方式

```
使用 character-design-prompt skill
输入目录: <包含需求文档的目录>
输出目录: <提示词输出目录>
```
