# 角色设计提示词生成

将角色需求转化为专业的AI绘图提示词，**只输出角色设计图提示词**。

## 核心要求

角色设计图必须满足以下要求：

1. **透明背景**：背景必须透明，便于后期合成
2. **三视图**：包含正面、背面、侧面三个角度
3. **一致性**：同一角色在三视图中保持外观一致

## 输入

从 `01_需求文档/` 目录读取：

| 文件 | 必需 | 说明 |
|-----|-----|-----|
| 游戏基本信息.md | 是 | 提供美术风格、世界观背景 |
| 角色需求.md | 是 | 角色外观、性格、阵营等需求 |

## 输出

输出到 `02_角色设计/` 目录，两层文件夹结构：先按类型分类，再按角色ID建立独立文件夹：

```
02_角色设计/
├── 角色设计总览.md              # 所有角色的总结索引
├── 主角/                        # 第一层：按类型分类
│   ├── 主角ID_角色名/           # 第二层：按角色ID命名
│   │   └── 提示词.md            # 该角色的设计图提示词
│   └── ...
├── NPC/
│   ├── NPC_ID_名称/
│   │   └── 提示词.md
│   └── ...
└── 怪物/
    ├── 怪物ID_名称/
    │   └── 提示词.md
    └── ...
```

### 文件夹命名规则

**第一层**：角色类型文件夹
- `主角/`、`NPC/`、`怪物/`

**第二层**：角色ID文件夹
- 格式：`<角色ID>_<角色名称>`
- 示例：`liyun_李云`、`elder_zhang_张长老`、`slime_史莱姆`

### 角色设计总览.md 结构

详见 [overview-structure.md](references/overview-structure.md)

## 提示词格式

每个角色的 `提示词.md` 包含角色设计图提示词，格式如下：

```markdown
# [角色名称] 角色设计图提示词

## 角色信息
- 类型：主角/NPC/怪物
- 描述：简要外观描述

## 角色设计图（三视图）

### 提示词
角色设计图，透明背景，三视图，正面视图，背面视图，侧面视图，全身像，[角色外观描述]，[服装细节]，[配色方案]，[风格标签]

### 负面提示词
背景，场景，杂乱元素，阴影投射，模糊，低质量，变形

### 参考关键词
- 风格：[游戏风格]
- 视角：三视图 / 角色设定图
- 背景：透明
```

## 提示词语言要求

**重要**：所有生成的提示词必须使用**中文**。

- 提示词、负面提示词均使用中文描述
- 参考关键词部分可保留英文标签
- 示例：`角色设计图，透明背景，三视图，正面视图，背面视图，侧面视图，19岁男性主角，年轻战士，轻型外骨骼装甲...`

## 工作流程

1. 读取 `01_需求文档/游戏基本信息.md`，提取世界观背景
2. 读取 `01_需求文档/角色需求.md`，提取角色信息
3. **为每个角色创建独立文件夹**（按角色ID命名）
4. 在各角色文件夹内生成 `提示词.md`（包含角色设计图三视图提示词）
5. **生成 `角色设计总览.md`**，汇总所有角色的索引

## 更新逻辑

- 如果角色文件夹已存在，更新其中的 `提示词.md` 内容
- 每次运行时重新生成 `角色设计总览.md` 以保持同步

## 调用方式

```
使用 character-design-prompt skill
输入目录: 01_需求文档/
输出目录: 02_角色设计/
```
