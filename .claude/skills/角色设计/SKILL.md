# 角色设计提示词生成

将角色需求转化为专业的AI绘图提示词，输出**设计图提示词**和**动画提示词**。

## 目标模型

提示词面向 **Seedream 5.0 lite**（火山引擎豆包）编写，遵循其自然语言提示词规范。

## Seedream 提示词核心规则

1. **自然语言优先**：用简洁连贯的描述性语句，避免关键词堆叠
   - 推荐：`身穿轻型外骨骼装甲，机械感护肩覆盖双肩，胸甲贴合躯干`
   - 避免：`外骨骼, 机械护肩, 胸甲, 装甲`
2. **主体 + 行为/特征 + 环境 + 风格**：按此顺序组织描述
3. **明确用途**：开头声明图像类型（如"角色设计图"）
4. **风格词精准**：使用准确的风格词或提供参考图像
5. **不使用负面提示词**：Seedream 通过正面描述控制画面

## 执行流程

### 1. 获取任务

读取 `99_流程管理/backlog.yaml` 中 `task_id: 角色设计` 条目的 inputs。无此条目则提示用户 `/流程管理` 初始化。

### 2. 执行

1. 读取 inputs中提及的文件，缺失则终止报告
2. 提取世界观、美术风格、角色信息、动画需求
3. 为每个角色创建文件夹：

```
02_角色设计/
├── 角色设计总览.md
├── 主角/char_001/
│   ├── 设计图提示词.md    ← 本skill（按角色类型区分视角，纯白背景）
│   └── 动画/提示词.md      ← 本skill（只描述动作）
├── NPC/npc_001/
└── 怪物/enemy_001/
```

**命名规则**：第一层=角色类型（主角/NPC/怪物），第二层=角色ID（不含名称）

4. 生成提示词（模板见 references/）：
   - `设计图提示词.md` — 所有角色，自然语言描述，按角色类型区分视角+纯白背景（主角：正面/侧面/背面各一张；NPC：正面/背面各一张；怪物：面朝屏幕45°一张）
   - `动画/提示词.md` — 所有角色，只描述动作本身，不重复外观
5. 更新 `角色设计总览.md`（结构见 [references/overview-structure.md](references/overview-structure.md)）

已有角色文件夹时仅更新提示词内容，每次更新生成总览。

### 3. 写入 feedback

向 `99_流程管理/feedback.yaml` 追加：

```yaml
entries:
  - task_id: 角色设计
    skill: 角色设计
    executed_at: "<ISO时间>"
    processed: ["生成char_001设计图提示词", "生成char_001动画提示词"]
    unprocessed: ["npc_003待补充"]
    unable_to_process: []
```

## 提示词语言

所有提示词使用**中文**，采用自然语言描述。
