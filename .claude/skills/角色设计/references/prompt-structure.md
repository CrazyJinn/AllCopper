# 提示词结构指南

## 提示词生成思路

1. **画面内容**：用连贯的自然语言描述主体+行为+环境等
2. **画面美学**：用短词语描述风格、色彩、光影、构图等
3. **比例指定**：根据应用场景自动适配比例尺寸
4. **场景适配**：明确写出图像用途和类型

## 提示词结构

```
[连贯的自然语言描述画面内容：主体+行为+环境] + [短词语描述画面美学：风格、色彩、光影、构图] + [用途类型]
```

## 素材类型模板

### 立绘（对话用）

**说明**：立绘是正面、侧面、背面 的3视角图，透明背景

```
[主体外观描述]，[服装装备描述]，角色三视图，正面视图、侧面视图、背面视图并排展示，全身立绘，透明背景。[风格关键词]，[色彩关键词]，游戏角色立绘，用于对话场景。--ar 4:3
```

**适用场景**：剧情对话、角色选择界面、菜单展示
**比例**：4:3（横向三视图）

### 战斗形象（俯视角）

**说明**：俯视角战斗角色，正面+背面并排，透明背景

```
[主体外观描述]，[服装装备描述]，角色多方向视图，正面视图、背面视图并排展示，俯视角战斗角色，透明背景。[风格关键词]，游戏战斗角色设计，用于俯视角战斗场景。--ar 2:1
```

**适用场景**：俯视角战斗场景中的角色显示
**比例**：2:1（横向双视图）

### 头像（UI用）

**说明**：头部特写，透明背景

```
[面部特征描述]，角色头像特写，透明背景。[风格关键词]，[色彩关键词]，游戏角色头像，用于UI对话框。--ar 1:1
```

**适用场景**：对话框、状态栏、队伍界面
**比例**：1:1（正方形）

## 示例

17岁少年，黑色短发，身材匀称偏瘦，穿着骑士团黑白灰配色轻型外骨骼机甲，机甲表面有划痕和磨损痕迹，腰间佩戴能量剑，自然站立姿势，角色三视图，正面视图、侧面视图、背面视图并排展示，全身立绘，透明背景。日系游戏原画风格，手绘风格，废土科幻，游戏角色立绘，用于对话场景。--ar 4:3

```

```

## 注意事项

- **不要表情描述**：提示词中不包含表情、情绪等描述
- **风格从需求读取**：美术风格由角色需求.md决定
- **透明背景**：所有素材均为透明背景，便于后续使用
- **无环境**：纯角色设计图，不包含背景环境
- **立绘三视图**：立绘必须包含正面、侧面、背面三个视角并排展示
