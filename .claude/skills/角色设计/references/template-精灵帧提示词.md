# 精灵帧提示词模板

> **核心原则**：基于手绘Q版风格角色设计图生成精灵帧图（9宫格排列），只描述动作关键帧节点，不重复描述角色外观、服装、风格等。

---

## 方向配置

**重要**：动画方向数应根据项目需求动态确定。

### 配置来源
从 `01_需求文档/角色需求.md` 的精灵图规格中读取：
- 搜索关键词："方向"、"翻转"、"正面"、"背面"

### 常见配置

| 方向数 | 说明 | 提示词写法 |
|-------|------|----------|
| 1方向 | 侧面，左右翻转 | 每个动画1个提示词，注明侧面视角 |
| 2方向 | 正面+背面，左右翻转 | 每个动画2个提示词，见下方格式 |
| 4方向 | 上、下、左、右 | 每个动画4个提示词 |
| 8方向 | 含斜角 | 每个动画8个提示词 |

### 2方向提示词格式（正面+背面）

```markdown
- **提示词**：
  - 正面：9宫格（3行3列），纯白背景，3/4 front left view。9格依次展示[动画名称]：[关键帧A] → [关键帧B] → [关键帧C] → [关键帧D]。角色在各格中保持同一形象。
  - 背面：9宫格（3行3列），纯白背景，3/4 back left view。9格依次展示[动画名称]：[关键帧A] → [关键帧B] → [关键帧C] → [关键帧D]。角色在各格中保持同一形象。
```

**镜头描述规则**：
- 正面统一：`3/4 front left view`
- 背面统一：`3/4 back left view`
- 不再需要"面朝镜头方向"或"背对镜头方向"等补充说明，视角已由英文术语明确
- 动作描述内容正面/背面基本相同（同一个动作，不同视角）

## 编写要点

### 核心原则
1. **不描述**：角色外观、服装、配色、艺术风格等（这些在手绘Q版风格设计图中已有）
2. **只描述**：动作关键帧节点，用 `→` 连接
3. **基于性格**：根据角色性格定制动作风格和力度感
4. **简洁优先**：每个动画3-5个关键帧节点即可，让模型自行填充过渡帧

### 提示词固定结构
- 正面前缀：`9宫格（3行3列），纯白背景，3/4 front left view。`
- 背面前缀：`9宫格（3行3列），纯白背景，3/4 back left view。`
- 动作描述：`9格依次展示[动画名称]：[关键帧A] → [关键帧B] → ...`
- 固定后缀：`角色在各格中保持同一形象。`
- 循环动画（待机、移动）使用"循环"标注，非循环动画不标注

### 动作描述要素
- **身体姿态**：前倾/后仰/侧转/蹲伏
- **重心变化**：前移/后移/下蹲/跳跃
- **四肢动作**：摆动/挥舞/踢腿/抬手
- **力度感**：干脆/柔和/有力/轻盈
- **节奏**：快速/缓慢/均匀/变速

### 背面提示词可见性规则（重要）

**背面视角只描述从背后能看到的动作和姿态，绝不描述被身体遮挡的正面细节。**

**从背后不可见的元素（禁止出现在背面提示词中）：**
- 双手在身前的动作：`双手自然交叠于身前`、`双手护住胸前`、`单手护胸`
- 面部表情和五官细节：`微笑`、`痛苦表情`、`眼睛睁大`
- 头部细微动作：`头部左右张望`、`眼神警惕`（大幅度抬头/低头勉强可见）
- 前方动作细节：`向前伸出`、`向前推`、`挥向镜头方向`
- 正面身体部位：`胸前`、`腹部`、`面部`

**从背后可见的元素（可以出现在背面提示词中）：**
- 整体身体姿态：前倾/后仰/下蹲/站直
- 背部和肩胛骨运动
- 双臂大幅度动作（举手/放下/摆动，即使手在身前，大臂运动从背后可见）
- 头部大幅度动作（仰头/低头/转头到侧面）
- 呼吸引起的背部起伏
- 步伐和移动
- 尾巴/翅膀/披风等后方附属物的运动

**负面样例：**
```
❌ 背面：9宫格（3行3列），纯白背景，3/4 back left view。9格依次展示待机循环：双手自然交叠于身前 → 单手叉腰摩挲胸前吊坠 → 恢复站立。角色在各格中保持同一形象。
↑ 错误："双手交叠于身前"、"摩挲胸前吊坠" 从背后看不到

✅ 背面：9宫格（3行3列），纯白背景，3/4 back left view。9格依次展示待机循环：自然站立 → 背部随呼吸缓缓起伏 → 双臂微微摆动 → 恢复站立。角色在各格中保持同一形象。
↑ 正确：只描述从背后能看到的背部起伏、手臂摆动、整体姿态
```
