# 动画提示词模板

> **i2v环节核心原则**：基于Q版角色设计图进行图生视频，只描述动作本身，不重复描述角色外观、服装、风格等。

---

## 方向配置

**重要**：动画方向数应根据项目需求动态确定。

### 配置来源
从 `01_需求文档/角色需求.md` 的精灵图规格中读取：
- 搜索关键词："方向"、"翻转"、"正面"、"背面"

### 常见配置

| 方向数 | 说明 | 提示词写法 |
|-------|------|----------|
| 1方向 | 侧面，左右翻转 | 每个动画1个提示词，注明"侧面视角" |
| 2方向 | 正面+背面，左右翻转 | 每个动画2个提示词（正面/背面） |
| 4方向 | 上、下、左、右 | 每个动画4个提示词 |
| 8方向 | 含斜角 | 每个动画8个提示词 |

---

## 基础模板

```markdown
# [角色名称] 动画提示词

## 角色性格与动作风格
- [性格关键词]：如"坚毅冷静"
- [动作风格]：性格如何影响动作表现（如：动作干脆利落、步伐稳健）

## 方向配置
- **方向数**：[从需求文档读取，如：2方向]
- **方向列表**：[如：正面、背面]
- **左右翻转**：[是/否]

## 动画列表

### 待机动画
- **描述**：自然站立，轻微晃动，有呼吸感
- **提示词**：待机动作，轻微晃动，呼吸起伏，身体重心平稳，循环动画，纯白背景
- **时长**：2-4秒循环
- **帧率**：12-24FPS

### 行走动画
- **描述**：侧面行走，脚步自然
- **提示词**：行走动作，侧面视角，脚步交替，身体微微起伏，循环动画，纯白背景
- **时长**：0.5-1秒循环
- **帧率**：12-24FPS

### 奔跑动画
- **描述**：快速奔跑，身体前倾
- **提示词**：奔跑动作，侧面视角，身体前倾，步伐加大，双臂摆动，循环动画，纯白背景
- **时长**：0.3-0.5秒循环
- **帧率**：12-24FPS

### 攻击动画
- **描述**：[攻击动作描述]
- **提示词**：攻击动作，[具体动作描述]，身体发力，动态姿势，纯白背景
- **时长**：0.5-1秒
- **帧率**：12-24FPS

### 受伤动画
- **描述**：受到伤害后仰
- **提示词**：受伤动作，身体后仰，重心不稳，痛苦反应，纯白背景
- **时长**：0.3-0.5秒
- **帧率**：12-24FPS

### 死亡动画
- **描述**：倒下消散
- **提示词**：死亡动作，缓慢倒下，身体无力，四肢松弛，纯白背景
- **时长**：1-2秒
- **帧率**：12-24FPS
```

## 编写要点

### 核心原则
1. **不描述**：角色外观、服装、配色、艺术风格等（这些在Q版设计图中已有）
2. **只描述**：动作本身、身体姿态、运动轨迹、力度感
3. **基于性格**：根据角色性格定制动作风格

### 动作描述要素
- **身体姿态**：前倾/后仰/侧转/蹲伏
- **重心变化**：前移/后移/下蹲/跳跃
- **四肢动作**：摆动/挥舞/踢腿/抬手
- **力度感**：干脆/柔和/有力/轻盈
- **节奏**：快速/缓慢/均匀/变速

### 帧数参考
| 动画类型 | 帧数 | 时长 |
|---------|-----|-----|
| 待机 | 4-8帧 | 2-4秒循环 |
| 行走 | 6-8帧 | 0.5-1秒循环 |
| 奔跑 | 4-6帧 | 0.3-0.5秒循环 |
| 攻击 | 4-6帧 | 0.5-1秒 |
| 受伤 | 2-4帧 | 0.3-0.5秒 |
| 死亡 | 6-12帧 | 1-2秒 |
