# 角色设计图提示词模板

> 基于 Seedream 5.0 lite 提示词规范编写。核心原则：**用简洁连贯的自然语言描述画面**，避免关键词堆叠。

---

## 基础模板（手绘动漫风格）

```markdown
# [角色名称] 设计图提示词（手绘动漫）

## 角色信息
- **类型**：主角/NPC/怪物
- **性别**：[性别]
- **年龄**：[年龄]
- **阵营**：[阵营]
- **描述**：[简要外观描述]

## 角色设计图

### 提示词
[用自然语言写一段完整的画面描述，包含以下要素：]

1. **开头声明用途**：角色设计图，纯白背景，45度角面朝屏幕（或45度角背朝屏幕）
2. **主体描述**：45°斜侧面全身像
3. **角色外貌**：年龄、体型、五官、发型等
4. **服装装备**：款式、材质、细节装饰
5. **配色方案**：主色、辅色、点缀色
6. **风格标签**：手绘动漫风格（放在末尾）

### 参考关键词
- 风格：手绘动漫风格
- 阵营：[阵营配色体系]
- 视角：45度角面朝屏幕 / 45度角背朝屏幕
- 背景：纯白
```

## 基础模板（手绘Q版风格风格）

> 手绘Q版风格设计图是精灵图的参考基准，需要在保持角色辨识度的同时简化为3头身比例。

```markdown
# [角色名称] 手绘Q版风格设计图提示词

## 角色信息
- **类型**：主角/NPC/怪物
- **性别**：[性别]
- **年龄**：[年龄]
- **阵营**：[阵营]
- **描述**：[简要外观描述]

## 手绘Q版风格角色设计图

### 提示词
[用自然语言写一段完整的画面描述，包含以下要素：]

1. **开头声明用途**：角色设计图，纯白背景，[根据角色类型填写视角]
2. **主体描述**：[根据下表选择视角]，全身像
3. **手绘Q版风格比例**：手绘Q版风格风格，3头身比例，大头小身
4. **角色特征简化**：保留标志性特征（发型、装备、配色），简化细节
5. **表情**：无表情
6. **风格标签**：手绘Q版风格，3头身（放在末尾）

### 参考关键词
- 风格：手绘Q版风格（3头身）
- 阵营：[阵营配色体系，可适当提亮/饱和]
- 视角：45度角面朝屏幕 / 45度角背朝屏幕
- 背景：纯白
```

### 手绘Q版风格设计图专用规则

1. **保留辨识度**：必须保留角色最标志性的特征（发型、核心装备、主色调），确保从手绘Q版风格能识别出对应角色
2. **简化而非丢失**：复杂装饰简化为色块或轮廓，但核心元素不可省略
3. **配色可微调**：手绘Q版风格可适当提高色彩饱和度和明度，使角色更鲜活
4. **表情更丰富**：手绘Q版风格角色的表情可以比手绘动漫版更夸张生动
5. **视角同手绘动漫**：主角/NPC两张（正面+背面），怪物一张（面朝屏幕45°）
6. **纯白背景**：必须在提示词中包含"纯白背景"

### 视角要求（按角色类型）

> 手绘动漫设计图和手绘Q版风格设计图共用同一套视角规则。

| 角色类型 | 视角要求 | 提示词开头声明 |
|---------|---------|--------------|
| 主角 | 正面、背面各一张（共两张） | `角色设计图，纯白背景，45度角面朝屏幕` / `45度角背朝屏幕` |
| NPC | 正面、背面各一张（共两张） | `角色设计图，纯白背景，45度角面朝屏幕` / `45度角背朝屏幕` |
| 怪物 | 面朝屏幕45°一张（共一张） | `角色设计图，纯白背景，45度角面朝屏幕` |

**所有视角均为45°斜侧面**：正面=45°面朝屏幕（可看到面部的斜侧面），背面=45°背朝屏幕（可看到背部的斜侧面）。每个视角独立成一张图，确保全身像完整展示。

**注意**：怪物角色不生成手绘动漫设计图，只生成手绘Q版风格设计图。

## 编写要点

### Seedream 提示词核心规则

1. **自然语言优先**：用完整的描述性语句，而非逗号分隔的关键词
   - 推荐：`身穿轻型外骨骼装甲，机械感护肩覆盖双肩，胸甲贴合躯干`
   - 避免：`外骨骼, 机械护肩, 胸甲, 装甲`
2. **主体 + 细节 + 风格**：先写清楚主体，再补充细节和风格
3. **明确用途**：开头声明"角色设计图"让模型理解生成目标
4. **配色写成描述**：不要只写"黑白灰"，写成"装甲主体为黑色与深灰色搭配，关节处露出白色内衬"
5. **风格词放末尾**：美术风格和参考作品放在提示词最后

### 角色设计图专用规则

1. **视角按角色类型区分**：所有视角均为45°斜侧面。主角/NPC两张（45°面朝屏幕+45°背朝屏幕），怪物一张（45°面朝屏幕）
2. **每张图独立提示词**：每个视角使用独立的提示词，开头声明对应视角
3. **纯白背景**：必须在提示词中包含"纯白背景"
4. **全身像**：确保完整展示角色设计
5. **一致性**：同一角色的多张图之间保持外观一致
6. **不使用负面提示词**：Seedream 通过正面描述控制画面，无需负面提示词
