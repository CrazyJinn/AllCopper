# 角色设计图提示词模板

> 基于 Seedream 5.0 lite 提示词规范编写。核心原则：**用简洁连贯的自然语言描述画面**，避免关键词堆叠。

---

## 基础模板

```markdown
# [角色名称] 设计图提示词

## 角色信息
- **类型**：主角/NPC/怪物
- **性别**：[性别]
- **年龄**：[年龄]
- **阵营**：[阵营]
- **描述**：[简要外观描述]

## 角色设计图

### 提示词
[用自然语言写一段完整的画面描述，包含以下要素：]

1. **开头声明用途**：角色设计图，纯白背景，[根据角色类型填写视角]
2. **主体描述**：[根据下表选择视角]，全身像
3. **角色外貌**：年龄、体型、五官、发型等
4. **服装装备**：款式、材质、细节装饰
5. **配色方案**：主色、辅色、点缀色
6. **风格标签**：美术风格、参考作品（放在末尾）

### 参考关键词
- 风格：[游戏美术风格]
- 阵营：[阵营配色体系]
- 视角：[根据角色类型填写]
- 背景：纯白
```

### 视角要求（按角色类型）

| 角色类型 | 视角要求 | 提示词开头声明 |
|---------|---------|--------------|
| 主角 | 正面、侧面、背面各一张（共三张） | `角色设计图，纯白背景，正面视图` / `侧面视图` / `背面视图` |
| NPC | 正面、背面各一张（共两张） | `角色设计图，纯白背景，正面视图` / `背面视图` |
| 怪物 | 面朝屏幕45°一张（共一张） | `角色设计图，纯白背景，面朝屏幕45度角` |

**主角**：每个视角独立成一张图，分别在提示词中声明对应视角，确保全身像完整展示。
**NPC**：正面和背面各独立一张图，分别在提示词中声明对应视角。
**怪物**：只需一张45°斜侧面图，强调面朝屏幕的方向感。

## 编写要点

### Seedream 提示词核心规则

1. **自然语言优先**：用完整的描述性语句，而非逗号分隔的关键词
   - 推荐：`身穿轻型外骨骼装甲，机械感护肩覆盖双肩，胸甲贴合躯干`
   - 避免：`外骨骼, 机械护肩, 胸甲, 装甲`
2. **主体 + 细节 + 风格**：先写清楚主体，再补充细节和风格
3. **明确用途**：开头声明"角色设计图"让模型理解生成目标
4. **配色写成描述**：不要只写"黑白灰"，写成"装甲主体为黑色与深灰色搭配，关节处露出白色内衬"
5. **风格词放末尾**：美术风格和参考作品放在提示词最后

### 角色设计图专用规则

1. **视角按角色类型区分**：主角三张（正面+侧面+背面），NPC两张（正面+背面），怪物一张（面朝屏幕45°）
2. **每张图独立提示词**：每个视角使用独立的提示词，开头声明对应视角
3. **纯白背景**：必须在提示词中包含"纯白背景"
4. **全身像**：确保完整展示角色设计
5. **一致性**：同一角色的多张图之间保持外观一致
6. **不使用负面提示词**：Seedream 通过正面描述控制画面，无需负面提示词
