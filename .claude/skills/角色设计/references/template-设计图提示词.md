# 角色设计图提示词模板

> 基于 Seedream 5.0 lite 提示词规范编写。核心原则：**用简洁连贯的自然语言描述画面**，避免关键词堆叠。

---

## 基础模板

```markdown
# [角色名称] 设计图提示词

## 角色信息
- **类型**：主角/NPC/怪物
- **性别**：[性别]
- **年龄**：[年龄]
- **阵营**：[阵营]
- **描述**：[简要外观描述]

## 角色设计图（三视图）

### 提示词
[用自然语言写一段完整的画面描述，包含以下要素：]

1. **开头声明用途**：角色设计图，纯白背景，三视图
2. **主体描述**：正面视图、背面视图、侧面视图，全身像
3. **角色外貌**：年龄、体型、五官、发型等
4. **服装装备**：款式、材质、细节装饰
5. **配色方案**：主色、辅色、点缀色
6. **风格标签**：美术风格、参考作品（放在末尾）

### 参考关键词
- 风格：[游戏美术风格]
- 阵营：[阵营配色体系]
- 视角：三视图 / 角色设定图
- 背景：纯白
```

## 示例：罗兰（科技阵营主角）

```markdown
# 罗兰 设计图提示词

## 角色信息
- **类型**：主角
- **性别**：男
- **年龄**：19岁
- **阵营**：骑士团（科技阵营）
- **描述**：少年体型，轻型外骨骼装备，黑白灰配色，参考条顿骑士团风格

## 角色设计图（三视图）

### 提示词
角色设计图，纯白背景，三视图（正面视图、背面视图、侧面视图），全身像。一个19岁男性角色，少年体型，身材匀称偏瘦。黑色短发，眼神坚毅。身穿轻型外骨骼装甲，机械感护肩覆盖双肩，胸甲贴合躯干，手臂外侧装有外骨骼动力装置。装甲主体为黑色与深灰色搭配，关节处露出白色内衬，护肩边缘和胸甲中央有深红色条纹点缀。下身穿着条顿骑士风格的长袍下摆，覆盖到大腿中部，内搭黑色长裤和机械战靴。腰系战术腰带，挂有小型工具包。手绘动漫风格，末世废土设定，角色设定参考条顿骑士团与疯狂的麦克斯。

### 参考关键词
- 风格：手绘动漫风格，末世废土，疯狂的麦克斯，赛博朋克元素
- 阵营：科技阵营（黑白灰/深红）
- 视角：三视图 / 角色设定图
- 背景：纯白
```

## 编写要点

### Seedream 提示词核心规则

1. **自然语言优先**：用完整的描述性语句，而非逗号分隔的关键词
   - 推荐：`身穿轻型外骨骼装甲，机械感护肩覆盖双肩，胸甲贴合躯干`
   - 避免：`外骨骼, 机械护肩, 胸甲, 装甲`
2. **主体 + 细节 + 风格**：先写清楚主体，再补充细节和风格
3. **明确用途**：开头声明"角色设计图"让模型理解生成目标
4. **配色写成描述**：不要只写"黑白灰"，写成"装甲主体为黑色与深灰色搭配，关节处露出白色内衬"
5. **风格词放末尾**：美术风格和参考作品放在提示词最后

### 角色设计图专用规则

1. **三视图必须**：正面、背面、侧面三个角度，在提示词开头明确声明
2. **纯白背景**：必须在提示词中包含"纯白背景"
3. **全身像**：确保完整展示角色设计
4. **一致性**：同一角色在三视图中保持外观一致
5. **不使用负面提示词**：Seedream 通过正面描述控制画面，无需负面提示词
