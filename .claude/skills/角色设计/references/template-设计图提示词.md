# 角色设计图提示词模板

## 基础模板

```markdown
# [角色名称] 设计图提示词

## 角色信息
- **类型**：主角/NPC/怪物
- **性别**：[性别]
- **年龄**：[年龄]
- **阵营**：[阵营]
- **描述**：[简要外观描述]

## 角色设计图（三视图）

### 提示词
角色设计图，纯白背景，三视图，正面视图，背面视图，侧面视图，全身像，[详细外观描述]，[服装细节]，[配色方案]，[风格标签]

### 负面提示词
背景，场景，杂乱元素，阴影投射，模糊，低质量，变形，多个角色，复杂背景，水印，签名

### 参考关键词
- 风格：[游戏风格]
- 阵营：[阵营配色]
- 视角：三视图 / 角色设定图
- 背景：纯白
```

---

## 示例

```markdown
# XX 设计图提示词

## 角色信息
- **类型**：主角
- **性别**：男
- **年龄**：19岁
- **阵营**：骑士团（科技阵营）
- **描述**：少年体型，轻型外骨骼装备，黑白灰配色，参考条顿骑士团风格

## 角色设计图（三视图）

### 提示词
角色设计图，纯白背景，三视图，正面视图，背面视图，侧面视图，全身像，19岁男性，少年体型，身材匀称偏瘦，轻型外骨骼装甲，机械感护肩，胸甲，手臂外骨骼装置，黑白灰配色为主，深红色点缀，条顿骑士风格长袍下摆，战术腰带，黑色长裤，机械战靴，黑色短发，眼神坚毅，手绘风格，游戏角色设定，末世废土风格

### 负面提示词
背景，场景，杂乱元素，阴影投射，模糊，低质量，变形，多个角色，复杂背景，水印，签名

### 参考关键词
- 风格：手绘风格，末世废土，疯狂的麦克斯，赛博朋克元素
- 阵营：科技阵营（黑白灰/深红）
- 视角：三视图 / 角色设定图
- 背景：纯白
```

---

## 编写要点

1. **三视图必须**：正面、背面、侧面三个角度
2. **纯白背景**：必须包含"纯白背景"
3. **全身像**：确保完整展示角色设计
4. **一致性**：同一角色在三视图中保持外观一致
