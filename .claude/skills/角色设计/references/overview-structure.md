## 美术风格统一

### 科技阵营（骑士团）
- **色彩**: 黑、白、灰、深红点缀
- **元素**: 外骨骼装备、机械感、战术装备
- **参考**: 条顿骑士团、疯狂的麦克斯、赛博朋克

### 魔法阵营（秘术协会/教会）
- **色彩**: 紫色（秘术协会）、金白色（教会）
- **元素**: 魔法符文、斗篷、长袍
- **参考**: 东方神秘、梵蒂冈教廷

### 怪物
- **动物类**: 辐射变异、金属化
- **植物类**: 突变生长、有毒化
- **色彩**: 灰绿、紫绿、红黑等病态色调

## 结构说明

### 角色区块结构

每个角色独立成一个区块，包含：

1. **资源类型表格**：记录设计图整体状态
2. **立绘表情状态表格**：每个表情独立跟踪状态
3. **动画状态表格**：每个动作独立跟踪状态

### 状态更新示例

生成完成后更新：

```markdown
**立绘表情状态：**
| 表情 | 状态 | 文件名 |
|-----|------|--------|
| 平静 | 初稿 | 平静.jpeg |
| 微笑 | 生成中 | - |
| 愤怒 | 提示词 | - |
...
```
