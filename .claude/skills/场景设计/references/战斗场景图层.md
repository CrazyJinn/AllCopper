## 房间类型

每个战斗场景包含多个房间，按推进顺序排列：

| 房间类型 | 目录命名 | 装饰密度 | 遮罩特征 | 氛围 |
|---------|---------|---------|---------|------|
| 入口房 | `room_001_入口房` | 稀疏 | 轻薄通透 | 宁静、安全、准备区 |
| 普通战斗房 | `room_xxx_普通战斗房N` | 中等 | 标准遮挡 | 紧张、危险 |
| 精英房 | `room_xxx_精英房` | 较密 | 厚重压迫 | 高度紧张、压迫感 |
| Boss房 | `room_xxx_Boss房` | 密集且戏剧化 | 厚重+能量光效 | 史诗、威压 |
| 隐藏房 | `room_xxx_隐藏房` | 独特稀有 | 神秘幽深 | 神秘、未知 |

## 概览格式

阶段一生成 `概览.md`，包含场景信息、房间列表和**逐项尺寸规格**。

### 尺寸规格

概览中须为每个房间的**每一个装饰物和遮罩**逐一列出内容与尺寸，JSON 中不再描述尺寸：

- **装饰物尺寸**：占9宫格单格的百分比（如 30%、60%）
- **遮罩尺寸**：独立图片的画幅大小（如 1920×400、1920×600）

## 装饰层（9宫格 / 4宫格）

装饰物按大小分两档，各自独立 JSON 文件：

| 类型 | 宫格 | 文件命名 | 每元素空间 | 适用 |
|------|------|---------|-----------|------|
| 小装饰 | 3×3 = 9格 | `装饰层_1.json` | 1格 | 碎石、弹壳、枯枝等 |
| 大装饰 | 2×2 = 4格 | `装饰层_2.json` | 约2格面积 | 废弃车辆、岩石堆、大树桩等 |

**仅描述色调**，不描述形状、材质、大小。装饰多时可继续追加（`装饰层_3.json`...）。

```json
{
  "layer": "装饰层（Decoration）",
  "scene": "[场景名称]",
  "room": "[房间名称]",
  "requirement": "无任何文字,每个元素独立完整,格子之间用1px细线隔开,元素居中占格子80%",
  "style": {
    "background": "纯白背景,格子之间用1px细线隔开",
    "camera": "俯视角",
    "rendering": "油画风格,手绘质感"
  },
  "order": [
    "1", "2", "3",
    "4", "5", "6",
    "7", "8", "9"
  ],
  "elements": {
    "count": 9,
    "items": [
      { "label": "1", "description": "[仅色调描述]" },
      { "label": "2", "description": "[仅色调描述]" },
      { "label": "3", "description": "[仅色调描述]" },
      { "label": "4", "description": "[仅色调描述]" },
      { "label": "5", "description": "[仅色调描述]" },
      { "label": "6", "description": "[仅色调描述]" },
      { "label": "7", "description": "[仅色调描述]" },
      { "label": "8", "description": "[仅色调描述]" },
      { "label": "9", "description": "[仅色调描述]" }
    ]
  }
}
```

## 遮罩层（独立图片）

每个遮罩是独立的JSON文件，一个房间可有多个遮罩。文件命名：`遮罩层_1.json`、`遮罩层_2.json`...

```json
{
  "layer": "前景/遮罩层（Foreground/Mask）",
  "scene": "[场景名称]",
  "room": "[房间名称]",
  "mask_id": 1,
  "requirement": "无任何文字,元素独立完整",
  "style": {
    "background": "纯白背景",
    "camera": "俯视角",
    "rendering": "油画风格,手绘质感"
  },
  "elements": {
    "count": 1,
    "items": [
      { "label": "1", "description": "[遮罩的色调与位置描述]" }
    ]
  }
}
```

## 编写要点

- **概览是唯一计划源**：每个房间的装饰物和遮罩须在概览中逐一列出内容与尺寸，JSON 严格按概览生成
- **装饰层**：description 仅描述色调（如"黄褐色调的碎石"），不描述形状、材质、大小
- **装饰分档**：小装饰用9宫格（`装饰层_1.json`），大装饰用4宫格（`装饰层_2.json`），数量不限可追加
- **装饰尺寸**：每个装饰物占格百分比在概览.md 中逐项定义，不在 JSON 中重复
- **遮罩尺寸**：每个遮罩的像素尺寸在概览.md 中逐项定义（如 1920×400），不在 JSON 中重复
- **遮罩数量**：每个房间遮罩数量不限，每个独立一个JSON文件
- 装饰密度按房间类型区分（见房间类型表）
- Boss房可包含能量光效等戏剧化色调描述
- 入口房色调宜柔和平和，营造安全感
