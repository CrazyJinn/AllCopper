# 场景提示词结构指南

## 输出要求

- **分层描述**: 远景、中景、近景
- **无角色**: 纯场景背景
- **风格统一**: 与游戏美术风格一致
- **可拼接**: 背景层可循环或-物品层独立

## 场景背景模板

### 结构
```
[场景名]，[类型]，[时间]，[天气]，[氛围]，[远景描述]，[中景描述]，[近景描述]，[光照描述]，[风格]，游戏场景背景图，高质量
```

### 示例： 废土场景
```
核战后的废土世界，室外场景，黄昏，阴天，荒凉危险的氛围，远景是废弃城市轮廓和核爆坑和远处的风暴云，中景是废弃车辆和倒塌建筑和辐射标志，近景是碎石和瓦砾和废弃物品，主光源来自左侧呈橙红色，环境光灰暗，油画风格，游戏场景背景图，高质量
```

## 场景物品模板

