# 场景设计提示词指南

本文档提供场景设计提示词的编写规范和示例参考。

> **硬性约束**（配色、美术风格、风格关键词）和 **Seedream 提示词要点**见 [SKILL.md](../SKILL.md)，生成提示词时必须遵守。

## 提示词结构

### 基础结构

用自然语言描述场景，按 **用途 → 主体 → 环境 → 光影 → 风格** 的顺序组织：

```
[用途]，[场景主题的自然语言描述]，[时间与天气]，[整体氛围]。
远景可以看到[远景的连贯描述]，中景是[中景的连贯描述]，近景是[近景的连贯描述]。
主光源从[方向]照射，呈现[颜色]色调，环境光[描述]。
[美术风格]，[风格参考]，无角色
```

### 结构说明

| 部分 | 说明 | 示例 |
|-----|------|------|
| 用途 | 图片用途，放在开头 | 游戏场景背景图、游戏对话背景图、游戏UI背景 |
| 场景主题 | 场景的核心主题，用自然语言描述 | 一座科技派阵营的城镇、核战后的废土世界 |
| 时间与天气 | 时间和天气的自然描述 | 白天晴朗、黄昏时分天空阴沉 |
| 氛围 | 整体氛围的连贯描述 | 街道整齐有序，充满机械化的秩序感、空气荒凉沉闷，充满危险气息 |
| 远景 | 最远处的视觉元素，写成连贯句子 | 远景可以看到高耸的金属建筑轮廓和升腾的烟囱 |
| 中景 | 中间距离的元素，写成连贯句子 | 中景是整齐排列的金属房屋和宽阔的街道 |
| 近景 | 最近的视觉元素，写成连贯句子 | 近景是带有管道和科技装置的金属地面 |
| 主光源 | 光源方向和颜色的自然描述 | 主光源从右上方照射，呈现冷白色调 |
| 环境光 | 环境光色调的自然描述 | 环境光偏蓝色，营造冷静的科技感 |
| 美术风格 | 整体美术风格，放末尾 | 油画风格，手绘质感，游戏美术 |

## 场景类型模板

### 功能场景

```
游戏场景背景图，[场景主题的完整描述]，[时间与天气]，[氛围的自然语言描述]。
远景可以看到[远景元素]，中景是[中景元素]，近景是[近景元素]。
主光源从[方向]照射，呈现[颜色]色调，环境光[描述]。
油画风格，手绘质感，游戏美术，[风格参考]，无角色
```

**示例 - 科技派城镇：**
```
游戏场景背景图，一座科技派阵营的城镇，白天晴朗，街道整齐有序，充满机械化的秩序感。远景可以看到高耸的金属建筑和烟囱，以及悬浮在空中的全息广告牌。中景是整齐排列的金属房屋和宽阔的街道。近景是布满管道和科技装置的金属地面。主光源从右上方照射，呈现冷白色调，环境光偏蓝色。油画风格，手绘质感，游戏美术，末世废土设定，蒸汽朋克，厚重，做旧处理，无角色
```

**示例 - 魔法派城镇：**
```
游戏场景背景图，一座魔法派阵营的城镇，黄昏时分，空气中弥漫着神秘魔幻的气息。远景可以看到漂浮的魔法水晶塔和发光的符文阵，紫色雾气在塔间缭绕。中景是带有魔法纹路的建筑，路边矗立着魔法路灯，半空中漂浮着发光的装饰物。近景是刻有魔法阵的地砖和散发着微光的植物。主光源从左上方照射，呈现金色调，环境光偏紫色。油画风格，手绘质感，游戏美术，末世废土设定，厚重，做旧处理，黑暗氛围，无角色
```

**示例 - 废土：**
```
游戏场景背景图，核战后的废土世界，黄昏时分天空阴沉，空气荒凉沉闷，充满危险气息。远景可以看到废弃城市的残破轮廓和巨大的核爆坑，远处有风暴云正在聚集。中景是倾覆的废弃车辆和倒塌的建筑残骸，路旁立着褪色的辐射警告标志牌。近景是散落的碎石、瓦砾和锈蚀的废弃物品。主光源从左侧照射，呈现暗橙红色调，环境光灰暗压抑。油画风格，手绘质感，游戏美术，末世废土设定，粗犷厚重，做旧处理，黑暗氛围，疯狂的麦克斯，无角色
```

### 战斗场景

```
远景是[房间后方元素]，中景是[房间中部元素]，近景是[近处细节]。
主光源从[光源]照射，呈现[颜色]色调，环境光[描述]。
油画风格，手绘质感，游戏美术，[风格元素]，无角色
```

**示例 - 战斗场景入口房：**
```
游戏场景背景图，战斗场景的入口房间，安全区域，宁静的准备区氛围。远景是房间后方的粗糙石墙，墙上插着燃烧的火把。中景是平整的石质地板和简单的石质装饰，角落放着供休息用的长凳。近景是地面上隐约可见的纹路和散落的物品碎片。主光源来自火把，呈现暖黄色调，环境光偏暗。油画风格，手绘质感，游戏美术，做旧处理，黑暗氛围，无角色
```

**示例 - Boss房：**
```
游戏场景背景图，战斗场景的Boss房间，最终战区域，充满史诗感和压迫感。远景是巨大的房间尽头，矗立着威严的Boss王座或祭坛。中景是刻有复杂符文的地板，周围散落着破碎的雕像和战斗留下的痕迹。近景是地面涌动的能量和强大的魔法光效。主光源从Boss所在位置照射，呈现暗红色或深紫色调，环境光充满能量感。油画风格，手绘质感，游戏美术，做旧处理，黑暗氛围，无角色
```

## 对话背景模板

```
游戏对话背景图，[场景主题的简洁描述]，[时间与氛围]。
远景是[简化的远景描述]，中景是[简化的中景描述]，近景是[模糊的近景描述]。
主光源从[方向]照射，环境光[柔和描述]。
油画风格，手绘质感，游戏美术，做旧处理，简洁构图，突出角色立绘，无角色
```

**要点：**
- 构图简洁，不干扰角色立绘
- 可适当模糊处理
- 保持氛围感但不喧宾夺主

## UI背景模板

```
游戏UI背景，[界面名称]，[风格的自然语言描述]，[装饰元素的描述]。整体主色调为[颜色]，环境光[描述]。
油画风格，手绘质感，游戏美术，做旧处理，简洁不干扰UI元素
```

**要点：**
- 极简设计，不干扰UI阅读
- 可有轻微纹理或装饰
- 色调统一，避免杂乱

## 提示词检查清单

生成提示词前，确认以下要点：

- [ ] 场景类型明确（室外/室内/对话背景/UI背景）
- [ ] 时间和天气设定合理
- [ ] 远中近景分层描述完整，使用自然语言
- [ ] 光源方向和颜色与氛围匹配
- [ ] 美术风格统一为"油画风格"
- [ ] 包含"无角色"
- [ ] 提示词开头声明用途
- [ ] 风格词放在末尾
- [ ] 根据场景类型添加风格元素（粗犷、厚重、蒸汽朋克、做旧处理、黑暗氛围）
