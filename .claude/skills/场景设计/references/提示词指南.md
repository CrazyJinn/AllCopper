# 场景设计提示词指南

本文档提供场景设计提示词的编写规范和示例参考。

## 提示词结构

### 基础结构

```
[场景主题]，[场景类型]，[时间]，[天气]，[氛围关键词]，
远景是[远景描述]，中景是[中景描述]，近景是[近景描述]，
主光源来自[光源方向和颜色]，环境光[环境光描述]，
[美术风格]，[用途]，无角色，高质量
```

### 结构说明

| 部分 | 说明 | 示例 |
|-----|------|------|
| 场景主题 | 场景的核心主题或名称 | 科技派阵营城镇、核战后的废土世界 |
| 场景类型 | 室内/室外/地图等 | 室外场景、室内场景、地图视图 |
| 时间 | 时间设定 | 白天、黄昏、夜晚、灰暗白天 |
| 天气 | 天气状况 | 晴朗、阴天、雾气弥漫、灰色雪花飘落 |
| 氛围关键词 | 整体氛围描述 | 秩序井然的机械化氛围、荒凉危险的氛围 |
| 远景 | 最远处的视觉元素 | 高耸的建筑轮廓、远处的风暴云 |
| 中景 | 中间距离的元素 | 街道、建筑、人物活动痕迹 |
| 近景 | 最近的视觉元素 | 地面纹理、小物件、细节 |
| 主光源 | 主要光源方向和颜色 | 来自右上方呈冷白色 |
| 环境光 | 环境光色调 | 偏蓝色、灰暗、神秘 |
| 美术风格 | 整体美术风格 | 油画风格 |
| 用途 | 图片用途 | 游戏场景背景图、游戏地图界面背景 |

## 场景类型模板

### 大地图

```
[世界观]全景地图，俯视角，地图视图，
远景是[不同区域的轮廓]，中景是[区域间的连接]，近景是[地图标记和标签]，
主光源来自上方均匀照射，环境光明亮，
油画风格，游戏地图界面背景，无角色，高质量
```

**示例：**
```
核战后废土世界全景地图，俯视角，地图视图，
远景是不同区域的地形轮廓包括废土平原和变异森林和城市废墟和灰雪地和两个阵营城镇，
中景是区域间的道路连接线，
近景是地图标记点和区域名称标签，
主光源来自上方均匀照射，环境光明亮，
油画风格，游戏地图界面背景，无角色，高质量
```

### 室外场景

```
[场景名]，室外场景，[时间]，[天气]，[氛围]，
```

```
核战后的废土世界，室外场景，黄昏，阴天，荒凉危险的氛围，
```

## 对话背景模板

```
[场景名]，对话背景，[时间]，[天气/氛围]，
远景是[简化远景]，中景是[简化中景]，近景是[模糊近景]，
主光源来自[方向]，环境光[柔和描述]，
油画风格，游戏对话背景图，简洁构图，突出角色立绘，无角色，高质量
```

**要点：**
- 构图简洁，不干扰角色立绘
- 可适当模糊处理
- 保持氛围感但不喧宾夺主

## UI背景模板

```
[UI名称]界面背景，[风格描述]，
[装饰元素描述]，
主色调[颜色]，环境光[描述]，
油画风格，游戏UI背景，简洁不干扰UI元素，高质量
```

**要点：**
- 极简设计，不干扰UI阅读
- 可有轻微纹理或装饰
- 色调统一，避免杂乱

## 负面提示词

用于排除不想要的元素：

### 通用负面提示词
```
角色，人物，文字，水印，签名，模糊，低质量，变形，杂乱元素
```

### 室外场景负面提示词
```
角色，人物，室内元素，家具，现代建筑，明亮色彩
```

### 室内场景负面提示词
```
角色，人物，室外元素，天空，树木，阳光直射
```

## 美术风格统一

所有场景使用统一的美术风格：

- **整体风格**：油画风格
- **色彩深度**：32位（含透明通道）
- **格式**：PNG

### 风格关键词
- 油画风格
- 手绘质感
- 游戏美术
- 末世废土风格
- 疯狂的麦克斯（参考）
- 赛博朋克元素（科技派）

## 提示词检查清单

生成提示词前，确认以下要点：

- [ ] 场景类型明确（大地图/室外/室内/对话背景/UI背景）
- [ ] 时间和天气设定合理
- [ ] 远中近景分层描述完整
- [ ] 光源方向和颜色与氛围匹配
- [ ] 美术风格统一为"油画风格"
- [ ] 包含"无角色"和"高质量"
- [ ] 负面提示词排除不需要的元素
