# 场景设计提示词生成

将场景需求转化为专业的AI绘图提示词（中文）。

## 硬性约束

生成每条提示词时，必须严格遵守以下规则：

### 美术风格

所有场景统一使用：
- **整体风格**：油画风格
- **色彩深度**：32位（含透明通道）
- **格式**：PNG
- 每条提示词必须包含风格关键词：`油画风格`、`手绘质感`、`游戏美术`

### 阵营配色

根据场景所属阵营/区域，严格匹配配色方案：

| 阵营/区域 | 主色调 | 光效 | 氛围关键词 |
|----------|-------|------|----------|
| 骑士团（科技） | 黑/白/灰 | 冷白色、蓝色 | 秩序、军事、机械化 |
| 秘术协会（魔法） | 紫/深蓝 | 紫色、金色 | 神秘、优雅、魔法 |
| 教会（魔法） | 金/白 | 金色、圣光 | 庄严、神圣、宗教 |
| 废土 | 黄褐/灰 | 橙红、灰暗 | 荒凉、危险、末世 |
| 变异森林 | 绿/紫 | 绿色、暗紫 | 阴森、变异、危险 |
| 灰雪地 | 灰白 | 灰蓝、苍白 | 极寒、死寂、辐射 |

### 风格关键词

根据场景背景选择性附加：
- 通用：`末世废土风格`
- 科技派场景：`赛博朋克元素`
- 参考基调：`疯狂的麦克斯`

## 执行流程

### 1. 获取任务

读取 `99_流程管理/backlog.yaml` 中 `task_id: 场景设计` 条目的 inputs。无此条目则提示用户 `/流程管理` 初始化。

### 2. 执行

1. 读取 inputs，缺失则终止报告
2. 提取美术风格、场景信息、阵营配色、UI背景需求
3. 按场景用途分类输出：

```
03_场景设计/
├── 场景设计总览.md
├── 游戏场景/
│   ├── 战斗场景/scene_xxx_场景名/提示词.md
│   └── 功能场景/scene_xxx_场景名/提示词.md
├── 对话背景/dialog_xxx_场景名/提示词.md   # 简洁，突出角色立绘
└── UI背景/ui_xxx_界面名/提示词.md         # 极简，不干扰UI
```

4. 为每个场景生成 `提示词.md`（含场景信息、提示词、负面提示词、参考关键词）
5. 更新 `场景设计总览.md`，追踪状态：提示词→初稿→终稿

#### 提示词结构

`[场景主题]，[场景类型]，[时间]，[天气]，[氛围]，远景是[...]，中景是[...]，近景是[...]，主光源来自[...]，环境光[...]，油画风格，[用途]，无角色，高质量`

详细模板与示例见 [references/提示词指南.md](references/提示词指南.md)

### 3. 写入 feedback

向 `99_流程管理/feedback.yaml` 追加：

```yaml
entries:
  - task_id: 场景设计
    skill: 场景设计
    executed_at: "<ISO时间>"
    processed: ["生成scene_001游戏场景提示词"]
    unprocessed: ["UI背景提示词待补充"]
    unable_to_process: []
```
