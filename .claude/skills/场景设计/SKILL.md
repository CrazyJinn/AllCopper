# 场景设计提示词生成

将场景需求转化为专业的AI绘图提示词（中文）。

## 目标模型

提示词面向 **Seedream 5.0 lite**（火山引擎豆包）编写，遵循其自然语言提示词规范。

## Seedream 提示词核心规则

1. **自然语言优先**：用简洁连贯的描述性语句，避免关键词堆叠
   - 推荐：`街道两旁整齐排列着金属房屋，屋顶的管道缓缓冒出白色蒸汽`
   - 避免：`金属房屋, 街道, 管道, 蒸汽, 科技装置`
2. **主体 + 环境 + 风格**：按此顺序组织描述
3. **明确用途**：在提示词中写明图像类型（如"游戏场景背景图"）
4. **风格词放末尾**：美术风格和参考作品放在提示词最后
5. **不使用负面提示词**：Seedream 通过正面描述控制画面

## 硬性约束

生成每条提示词时，必须严格遵守以下规则：

### 美术风格

所有场景统一使用：
- **整体风格**：油画风格
- **色彩深度**：32位（含透明通道）
- **格式**：PNG
- 每条提示词末尾须包含风格描述：`油画风格，手绘质感，游戏美术`

### 阵营配色

根据场景所属阵营/区域，严格匹配配色方案：

| 阵营/区域 | 主色调 | 光效 | 氛围关键词 |
|----------|-------|------|----------|
| 骑士团（科技） | 黑/白/灰 | 冷白色、蓝色 | 秩序、军事、机械化 |
| 秘术协会（魔法） | 紫/深蓝 | 紫色、金色 | 神秘、优雅、魔法 |
| 教会（魔法） | 金/白 | 金色、圣光 | 庄严、神圣、宗教 |
| 废土 | 黄褐/灰 | 橙红、灰暗 | 荒凉、危险、末世 |
| 变异森林 | 绿/紫 | 绿色、暗紫 | 阴森、变异、危险 |
| 灰雪地 | 灰白 | 灰蓝、苍白 | 极寒、死寂、辐射 |

### 风格参考

根据场景背景选择性附加：
- 通用：末世废土设定
- 科技派场景：赛博朋克元素
- 参考基调：疯狂的麦克斯

## 执行流程

### 1. 获取任务

读取 `99_流程管理/backlog.yaml` 中 `task_id: 场景设计` 条目的 inputs。无此条目则提示用户 `/流程管理` 初始化。

### 2. 执行

1. 读取 inputs，缺失则终止报告
2. 提取美术风格、场景信息、阵营配色、UI背景需求
3. 按场景用途分类输出：

```
03_场景设计/
├── 场景设计总览.md
├── 游戏场景/
│   ├── 战斗场景/scene_xxx_场景名/提示词.md
│   └── 功能场景/scene_xxx_场景名/提示词.md
├── 对话背景/dialog_xxx_场景名/提示词.md   # 简洁，突出角色立绘
└── UI背景/ui_xxx_界面名/提示词.md         # 极简，不干扰UI
```

4. 为每个场景生成 `提示词.md`（含场景信息、提示词、参考关键词）
5. 更新 `场景设计总览.md`，追踪状态：提示词→初稿→终稿

#### 提示词结构

用自然语言描述场景，按 **用途声明 → 主体描述 → 环境分层 → 光影 → 风格** 的顺序组织：

```
[用途]，[场景主题的自然语言描述]，[时间与天气]，[整体氛围]。
远景是[远景的连贯描述]，中景是[中景的连贯描述]，近景是[近景的连贯描述]。
主光源从[方向]照射，呈[颜色]色调，环境光[描述]。
[美术风格]，[风格参考]，无角色
```

详细模板与示例见 [references/提示词指南.md](references/提示词指南.md)

### 3. 写入 feedback

向 `99_流程管理/feedback.yaml` 追加：

```yaml
entries:
  - task_id: 场景设计
    skill: 场景设计
    executed_at: "<ISO时间>"
    processed: ["生成scene_001游戏场景提示词"]
    unprocessed: ["UI背景提示词待补充"]
    unable_to_process: []
```
