# 场景设计提示词生成

将场景需求转化为AI绘图提示词（中文），面向 **Seedream 5.0 lite**（火山引擎豆包）。

## Seedream 提示词要点

- 自然语言描述，不堆叠关键词
- 风格词放末尾，不使用负面提示词
- 提示词开头声明用途（如"游戏场景背景图"）

## 硬性约束

### 美术风格

所有场景统一使用：
- **整体风格**：油画风格
- **色彩深度**：32位（含透明通道）
- **格式**：PNG
- 每条提示词末尾须包含：`油画风格，手绘质感，游戏美术`

### 阵营配色

根据场景所属阵营/区域，严格匹配配色方案：

| 阵营/区域 | 主色调 | 光效 | 氛围关键词 |
|----------|-------|------|----------|
| 骑士团（科技） | 黑/白/灰 | 冷白色、蓝色 | 秩序、军事、机械化 |
| 秘术协会（魔法） | 紫/深蓝 | 紫色、金色 | 神秘、优雅、魔法 |
| 教会（魔法） | 金/白 | 金色、圣光 | 庄严、神圣、宗教 |
| 废土 | 黄褐/灰 | 橙红、灰暗 | 荒凉、危险、末世 |
| 变异森林 | 绿/紫 | 绿色、暗紫 | 阴森、变异、危险 |
| 灰雪地 | 灰白 | 灰蓝、苍白 | 极寒、死寂、辐射 |

- **通用**：末世废土设定
- **科技派**：蒸汽朋克
- **参考基调**：疯狂的麦克斯

## 执行流程

### 1. 获取任务

读取 `99_流程管理/backlog.yaml` 中 `task_id: 场景设计` 条目的 inputs。无此条目则提示用户 `/流程管理` 初始化。

### 2. 执行

1. 读取 inputs，缺失则终止报告
2. 提取美术风格、场景信息、阵营配色、UI背景需求
3. 按场景用途分类输出：

```
03_场景设计/
├── 场景设计总览.md
├── 游戏场景/
│   ├── 战斗场景/scene_xxx_场景名/
│   │   ├── 概览.md                      # 房间列表、尺寸规格、视觉规划
│   │   ├── room_xxx_房间名/
│   │   │   ├── 装饰层_1.json             # 9宫格小装饰（仅色调描述）
│   │   │   ├── 装饰层_2.json             # 4宫格大装饰（如需要）
│   │   │   ├── 遮罩层_1.json             # 独立前景遮罩
│   │   │   └── 遮罩层_2.json             # 独立前景遮罩（如需要）
│   │   └── ...
│   └── 功能场景/scene_xxx_场景名/提示词.md
├── 对话背景/dialog_xxx_场景名/提示词.md
└── UI背景/ui_xxx_界面名/提示词.md
```

4. 为每个场景生成提示词：
   - **功能场景/对话背景/UI背景**：生成 `提示词.md`（含场景信息、提示词）
   - **战斗场景**：先生成 `概览.md`（含尺寸规格），再逐房间生成装饰层JSON + 遮罩层JSON
5. 更新 `场景设计总览.md`，追踪状态：提示词→初稿→终稿

#### 提示词结构

按 **用途→主体→环境→光影→风格** 组织，末尾含风格描述和 `无角色`。详细模板与示例见 [references/提示词指南.md](references/提示词指南.md)

#### 战斗场景图层提示词

战斗场景按**两阶段**生成：

**阶段一：概览** — 生成 `概览.md`，按房间逐一列出每个装饰物和遮罩的内容、色调描述与具体尺寸。概览是唯一计划源，后续 JSON 严格按概览生成。

**阶段二：逐房间图层** — 严格按概览逐房间生成装饰层和遮罩层 JSON，description 须与概览完全一致：

- **装饰层**（9宫格/4宫格）：小装饰用9宫格（`装饰层_1.json`），大装饰用4宫格（`装饰层_2.json`），数量不限
- **遮罩层**（独立图片）：每个遮罩单独一个JSON文件，尺寸在概览中定义

房间类型、概览格式与 JSON 模板见 [references/战斗场景图层.md](references/战斗场景图层.md)

### 3. 写入 feedback

向 `99_流程管理/feedback.yaml` 追加：

```yaml
entries:
  - task_id: 场景设计
    skill: 场景设计
    executed_at: "<ISO时间>"
    processed: ["生成scene_001游戏场景提示词"]
    unprocessed: ["UI背景提示词待补充"]
    unable_to_process: []
```
