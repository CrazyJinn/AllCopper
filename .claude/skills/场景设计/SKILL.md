# 场景设计提示词生成

将场景需求转化为专业的AI绘图提示词（中文）。

## 执行流程

### 1. 获取任务

读取 `99_流程管理/backlog.yaml` 中 `task_id: 场景设计` 条目的 inputs/outputs。无此条目则提示用户 `/流程管理` 初始化。

### 2. 执行

1. 读取 inputs：`CLAUDE.md` + `01_需求文档/场景需求.md`，缺失则终止报告
2. 提取美术风格、场景信息、UI背景需求
3. 按场景用途分类输出：

```
03_场景设计/
├── 场景设计总览.md
├── 大地图/scene_xxx_场景名/提示词.md      # 俯视角地图
├── 游戏场景/
│   ├── 室内场景/scene_xxx_场景名/提示词.md
│   └── 室外场景/scene_xxx_场景名/提示词.md
├── 对话背景/dialog_xxx_场景名/提示词.md   # 简洁，突出角色立绘
└── UI背景/ui_xxx_界面名/提示词.md         # 极简，不干扰UI
```

4. 为每个场景生成 `提示词.md`（含场景信息、提示词、负面提示词、参考关键词）
5. 更新 `场景设计总览.md`，追踪状态：提示词→初稿→终稿
6. 验证 outputs 全部生成

#### 提示词结构

`[场景主题]，[场景类型]，[时间]，[天气]，[氛围]，远景是[...]，中景是[...]，近景是[...]，主光源来自[...]，环境光[...]，油画风格，[用途]，无角色，高质量`

详细模板与示例见 [references/提示词指南.md](references/提示词指南.md)

### 3. 写入 feedback

向 `99_流程管理/feedback.yaml` 追加：

```yaml
entries:
  - task_id: 场景设计
    skill: 场景设计
    executed_at: "<ISO时间>"
    processed: ["生成scene_001大地图提示词"]
    unprocessed: ["UI背景提示词待补充"]
    unable_to_process: []
```
