# 场景设计提示词生成

将场景需求转化为专业的AI绘图提示词（中文）。

## 输入

从 `01_需求文档/` 目录读取：

| 文件 | 必需 | 说明 |
|-----|-----|-----|
| 游戏基本信息.md | 是 | 提供美术风格、世界观背景 |
| 场景需求.md | 是 | 场景环境、物品、连接等信息 |
| UI需求.md | 是 | UI背景的风格、色调需求 |

## 输出

输出到 `03_场景设计/` 目录，按用途分类：

```
03_场景设计/
├── 场景设计总览.md              # 场景索引与状态追踪
├── 大地图/                      # 游戏世界地图、区域地图
│   └── scene_xxx_场景名/
│       └── 提示词.md
├── 游戏场景/                    # 实际游戏发生的场景
│   ├── 室内场景/
│   │   └── scene_xxx_场景名/
│   │       └── 提示词.md
│   └── 室外场景/
│       └── scene_xxx_场景名/
│           └── 提示词.md
├── 对话背景/                    # 对话系统的背景图
│   └── dialog_xxx_场景名/
│       └── 提示词.md
└── UI背景/                      # 界面背景（菜单、背包等）
    └── ui_xxx_界面名/
        └── 提示词.md
```

## 场景分类说明

| 分类 | 用途 | 特点 |
|-----|------|------|
| 大地图 | 世界地图、区域导航 | 俯视角，标注地点，可点击区域 |
| 游戏场景 | 玩家实际探索的场景 | 完整的远中近景分层，可交互区域 |
| 对话背景 | 对话系统背景 | 简洁，突出角色立绘，氛围感 |
| UI背景 | 菜单、背包、技能树等界面 | 简洁，不干扰UI元素阅读 |

## 提示词格式

每个场景生成一个 `提示词.md` 文件，格式如下：

```markdown
# 场景名称 提示词

## 场景信息
- **类型**: 大地图/室内/室外/对话背景/UI背景
- **时间**: 白天/黄昏/夜晚/动态
- **天气**: 晴朗/阴天/雨雪/雾气
- **状态**: 提示词/初稿/终稿

## 提示词

### 场景描述
[完整场景描述，包含：场景类型、时间天气、氛围、远景、中景、近景、主光源、环境光、美术风格、用途、无角色、高质量]

\`\`\`
[场景提示词内容，使用中文]
\`\`\`

### 负面提示词（可选）
\`\`\`
[需要避免的元素]
\`\`\`

## 参考关键词
- 风格：[美术风格参考]
- 阵营：[关联阵营及配色]
- 视角：[俯视角/侧视角等]
```

## 提示词编写指南

详细指南请参考：[提示词指南.md](./references/提示词指南.md)

### 核心原则

1. **简洁**：物品描述无需重复容器级风格（美术风格、视角、色调等）
2. **中文**：所有提示词使用中文
3. **分层**：远景、中景、近景分别描述
4. **结构化**：按固定顺序组织内容

### 提示词结构

```
[场景主题]，[场景类型]，[时间]，[天气]，[氛围关键词]，
远景是[远景描述]，中景是[中景描述]，近景是[近景描述]，
主光源来自[光源方向和颜色]，环境光[环境光描述]，
[美术风格]，[用途]，无角色，高质量
```

### 示例

```
科技派阵营城镇，室外场景，白天，晴朗，秩序井然的机械化氛围，
远景是高耸的金属建筑和烟囱和悬浮的全息广告牌，
中景是整齐的金属房屋和街道和巡逻的机器人守卫，
近景是金属地面和管道和科技装置，
主光源来自右上方呈冷白色，环境光偏蓝色，
油画风格，游戏场景背景图，无角色，高质量
```

## 状态管理

在 `场景设计总览.md` 中追踪每个场景的状态：

| 状态 | 说明 |
|-----|------|
| 提示词 | 已生成提示词，等待生成图片 |
| 初稿 | 已生成初步图片，待审核 |
| 终稿 | 图片已审核通过，可用于游戏 |

每次生成或更新提示词时，同步更新总览文件中的状态。

## 工作流程

1. 读取 `01_需求文档/游戏基本信息.md`，提取美术风格
2. 读取 `01_需求文档/场景需求.md`，提取场景信息
3. 读取 `01_需求文档/UI需求.md`，提取UI背景需求
4. 根据场景用途分类（大地图/游戏场景/对话背景/UI背景）
5. 为每个场景创建文件夹并生成 `提示词.md`
6. 更新 `场景设计总览.md` 汇总索引和状态
