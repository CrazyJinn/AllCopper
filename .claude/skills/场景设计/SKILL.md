# 场景设计提示词生成

将场景需求转化为专业的AI绘图提示词。

## 输入

| 文件 | 必需 | 说明 |
|-----|-----|-----|
| 游戏基本信息.md | 是 | 提供美术风格、世界观背景 |
| 场景需求.md | 是 | 场景环境、物品、连接等信息 |

## 输出

生成3个文件到指定目录：

```
输出目录/
├── 场景背景.md      # 各场景背景图提示词
├── 场景物品.md      # 场景物品/道具提示词
└── UI界面.md        # UI界面元素提示词
```

## 提示词要求

- **分层描述**: 远景、中景、近景分别描述
- **无角色**: 纯场景设计，- **风格统一**: 与游戏美术风格一致

## 工作流程

1. 读取游戏基本信息.md，提取美术风格
2. 读取场景需求.md
提取场景信息
3. 为每个场景生成背景提示词
4. 提取物品需求，生成物品提示词
5. 输出3个文件

## 调用方式

```
使用 scene-design-prompt skill
输入目录: <包含需求文档的目录>
输出目录: <提示词输出目录>
```
