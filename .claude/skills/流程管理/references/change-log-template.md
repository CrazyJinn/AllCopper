# 变更记录模板

变更记录用于追踪每次需求变更的历史。

## 文件位置

`99_变更管理/YYYY-MM-DD_变更标题/变更记录.md`

## 模板

```markdown
# 变更记录: <变更标题>

## 基本信息
- **变更日期**: YYYY-MM-DD
- **变更类型**: [新增/修改/删除]
- **变更范围**: [世界观/角色/场景/剧本/系统/UI/音频]
- **变更发起人**: <用户名>

## 变更内容

### 变更前
<描述变更前的状态，或引用原文>

### 变更后
<描述变更后的状态>

### 变更原因
<为什么需要这个变更>

## 影响分析

### 受影响文件
| 文件路径 | 影响程度 | 处理方式 |
|----------|----------|----------|
| 00_init/世界设定.md | 直接修改 | 人工编辑 |
| 01_需求文档/角色需求.md | 需更新 | 调用skill |
| 02_角色设计/... | 需更新 | 调用skill |

### 受影响流程
- [ ] 需求分析
- [ ] 剧本拆解
- [ ] 角色设计
- [ ] 场景设计
- [ ] 代码生成
- [ ] 资源搬运

## 执行记录

| 时间 | 执行内容 | 执行人 | 结果 |
|------|----------|--------|------|
| HH:MM | 更新世界设定.md | - | ✓ 完成 |
| HH:MM | 运行需求分析skill | - | ✓ 完成 |
| HH:MM | 运行角色设计skill | - | ✓ 完成 |

## 验收标准

- [ ] 所有受影响文件已更新
- [ ] 执行计划中所有任务已完成
- [ ] 新增/修改内容已审核
- [ ] 游戏中已验证生效

## 备注
<其他需要记录的信息>
```

## 变更类型说明

| 类型 | 说明 | 示例 |
|------|------|------|
| 新增 | 添加新内容 | 新增角色、新增场景、新增剧情 |
| 修改 | 修改现有内容 | 修改角色设定、修改场景描述 |
| 删除 | 删除内容 | 删除角色、删除剧情分支 |

## 影响程度说明

| 程度 | 说明 | 处理优先级 |
|------|------|------------|
| 直接修改 | 该文件是变更的直接目标 | 立即处理 |
| 需更新 | 该文件受上游变更影响 | 按依赖顺序处理 |
| 可能影响 | 该文件可能受影响，需评估 | 评估后决定 |
| 无影响 | 该文件不受影响 | 无需处理 |
