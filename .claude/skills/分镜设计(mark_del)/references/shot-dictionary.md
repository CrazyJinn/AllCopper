# 分镜提示词词典

## 运镜词典

| 运镜类型 | 提示词 | 使用场景 |
|---------|--------|---------|
| 切换 | 镜头切换 | 场景/视角转换 |
| 平移 | 镜头向上/下/左/右移动 | 展示环境、跟随移动 |
| 推轨 | 镜头拉近/拉远 | 强调细节或展示全貌 |
| 环形跟踪 | 镜头环绕、航拍、广角、镜头360度旋转 | 展示角色全貌、战斗场面 |
| 跟随 | 镜头跟随 | 角色移动、追逐戏 |
| 固定 | 固定镜头、镜头静止不动 | 对话、静态场景 |
| 聚焦 | 镜头特写 | 强调表情、物品细节 |
| 手持 | 镜头晃动/抖动、手持拍摄、动态不稳定 | 紧张、混乱、战斗场景 |

## 镜头类型

| 类型 | 提示词 | 效果 |
|------|--------|------|
| 远景 | 广角镜头、远景 | 展示环境全貌 |
| 全景 | 全景镜头、全身构图 | 展示角色全身 |
| 中景 | 中景镜头、半身构图 | 展示角色上半身 |
| 近景 | 近景镜头、胸部以上 | 展示面部表情 |
| 特写 | 特写镜头、面部特写 | 强调细节 |
