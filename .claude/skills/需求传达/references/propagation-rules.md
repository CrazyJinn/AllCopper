# 变更传达规则

## 层级传达原则

变更按照文档层级**逐级向下传达**，确保每一层都完成更新后再进入下一层。

## 第1层 → 第2层 传达规则

### 世界设定.md → 01_需求文档

| 世界设定章节 | 影响的需求文档 | 传达内容 |
|-------------|---------------|---------|
| 世界背景 | 游戏基本信息.md | 世界观概述、时代背景 |
| 势力设定 | 角色需求.md | NPC势力归属、组织关系 |
| 地理环境 | 场景需求.md | 地形地貌、气候特征 |
| 历史事件 | 游戏基本信息.md | 时间线、重大事件 |

### 剧本大纲.md → 01_需求文档

| 剧本大纲章节 | 影响的需求文档 | 传达内容 |
|-------------|---------------|---------|
| 角色列表 | 角色需求.md | 新增/修改角色信息 |
| 场景列表 | 场景需求.md | 新增/修改场景信息 |
| 剧情节点 | 代码需求.md | 触发条件、分支逻辑 |
| 对白文本 | 音频需求.md | 配音文本、情感标注 |

### 游戏概览.md → 01_需求文档

| 游戏概览章节 | 影响的需求文档 | 传达内容 |
|-------------|---------------|---------|
| 核心玩法 | 代码需求.md | 系统机制、交互逻辑 |
| 系统设计 | 代码需求.md | 功能模块、数据结构 |
| 美术风格 | 游戏基本信息.md | 视觉风格、色彩基调 |

## 第2层 → 第3层 传达规则

### 角色需求.md → 02_角色设计

| 角色需求变更 | 影响的设计文件 | 传达内容 |
|-------------|---------------|---------|
| 新增角色 | 创建新的角色文件夹 | 完整角色设计提示词 |
| 外观修改 | 对应角色的提示词.md | 更新外观描述 |
| 删除角色 | 标记删除或归档 | 通知移除相关资源 |

### 场景需求.md → 03_场景设计

| 场景需求变更 | 影响的设计文件 | 传达内容 |
|-------------|---------------|---------|
| 新增场景 | 创建新的场景文件夹 | 完整场景设计提示词 |
| 氛围修改 | 对应场景的提示词.md | 更新氛围描述 |
| 删除场景 | 标记删除或归档 | 通知移除相关资源 |

## 传达优先级

1. **高优先级**：影响核心玩法、主角设定、主要场景
2. **中优先级**：影响NPC、次要场景、支线剧情
3. **低优先级**：文本修正、数值微调、非关键美术调整

## 传达检查清单

- [ ] 确认变更类型和影响范围
- [ ] 更新第1层（00_init）对应文件
- [ ] 更新第2层（01_需求文档）受影响文件
- [ ] 通知第3层（02_角色设计 / 03_场景设计）需要更新的内容
- [ ] 在 `99_变更管理/` 目录下生成变更记录和变更通知
