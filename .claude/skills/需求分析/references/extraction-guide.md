# 信息提取指南

从世界观和设定集文档中提取以下关键信息：

## 游戏基本信息提取

- 游戏名称（如有）
- 核心玩法类型
- 目标平台
- 美术风格
- 世界观背景摘要
- 主要特色/卖点

## 角色信息提取

每个角色需提取：

| 字段 | 说明 |
|-----|-----|
| 角色名 | 角色的名称 |
| 类型 | 主角/NPC/敌人/宠物等 |
| 外观 | 外貌描述、服装、特征 |
| 性格 | 可影响配音/动画风格 |
| 出现场景 | 该角色在哪些场景出现 |
| 动作需求 | 需要的动作/表情动画 |
| 特殊需求 | 变身、特效、多形态等 |

## 场景信息提取

每个场景需提取：

| 字段 | 说明 |
|-----|-----|
| 场景名 | 场景的名称/地点名 |
| 类型 | 室内/室外/特殊 |
| 环境描述 | 时间、天气、氛围 |
| 背景元素 | 远景、中景要素 |
| 前景元素 | 可交互/遮挡物 |
| 光照 | 光源类型、色调 |
| 可交互物品 | 需要单独绘制的物品 |
| 过渡 | 与其他场景的连接方式 |

## 音频信息提取

### BGM需求
- 场景对应关系
- 情绪/风格要求
- 是否需要循环
- 参考曲目（如有）

### 音效需求
- 角色相关（脚步、语音、受击等）
- 环境音效（风声、水声等）
- UI音效
- 特殊事件音效

## 代码需求提取

根据游戏类型和设定，识别需要的系统：

| 系统类型 | 常见需求 |
|---------|---------|
| 核心玩法 | 移动、战斗、对话、探索 |
| UI系统 | 菜单、HUD、对话框 |
| 存档系统 | 存档位、自动存档 |
| 场景管理 | 场景切换、过渡动画 |
| 音频系统 | BGM切换、音效播放 |
| 资源管理 | 预加载、内存管理 |
