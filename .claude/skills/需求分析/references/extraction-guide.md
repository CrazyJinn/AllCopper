# 信息提取指南

从世界观和设定集文档中提取以下关键信息：

## 游戏基本信息提取

- 游戏名称（如有）
- 核心玩法类型
- 目标平台
- 美术风格
- 世界观背景摘要
- 主要特色/卖点

## 角色信息提取

每个角色需提取：

| 字段 | 说明 |
|-----|-----|
| 角色名 | 角色的名称 |
| 类型 | 主角/NPC/敌人/宠物等 |
| 外观 | 外貌描述、服装、特征 |
| 性格 | 可影响配音/动画风格 |
| 动作需求 | 需要的动作/表情动画 |
| 特殊需求 | 变身、特效、多形态等 |

## 场景信息提取

每个场景需提取：

### 基础信息
| 字段 | 说明 |
|-----|-----|
| 场景名 | 场景的名称/地点名 |
| 类型 | 大地图 / 副本房间 / 功能场景 / UI背景 |
| 场景分类 | 城镇 / 废土 / 森林 / 废墟 / 雪地 / 室内 / 其他 |
| 尺寸 | 地图像素尺寸（如1024×1024） |

### 环境设定
| 字段 | 说明 |
|-----|-----|
| 时间 | 白天 / 黄昏 / 夜晚 / 动态 |
| 天气 | 晴朗 / 阴天 / 雨天 / 雪 / 灰烬等 |
| 氛围 | 荒凉 / 紧张 / 神秘 / 安全等 |

### 地图图层（俯视角游戏）
| 图层 | 提取内容 |
|-----|---------|
| 地面层 | 主纹理类型、边缘过渡需求、Tile规格 |
| 装饰层 | 地面装饰（裂缝、污渍）、环境装饰物 |
| 碰撞层 | 阻挡物列表：墙壁、石块、建筑残骸等 |
| 遮罩层 | 可穿透的遮挡物：树冠、房顶等 |

### 功能区域
| 区域类型 | 提取内容 |
|---------|---------|
| 刷怪点 | 位置、怪物类型、数量、刷新规则 |
| 交互点 | 宝箱、NPC、传送门、机关等 |
| 特殊区域 | 安全区、危险区、触发区等 |

### 素材需求
| 类型 | 提取内容 |
|-----|---------|
| Tile需求 | 地面Tile、墙壁Tile数量和类型 |
| 装饰物 | 植被、废墟、杂物等 |
| 特效 | 粒子效果、动态光效 |

### 连接关系
| 字段 | 说明 |
|-----|-----|
| 入口 | 从哪些场景可进入 |
| 出口 | 可通往哪些场景 |

## UI信息提取

> 提取的 UI 信息写入代码需求.md 的 UI系统 章节。

### UI类型识别

| 类型 | 提取内容 |
|-----|---------|
| 战斗UI | HUD、血条、技能栏、小地图、伤害数字、Buff图标 |
| 菜单UI | 主菜单、暂停菜单、设置界面、存档界面 |
| 对话UI | 对话框、角色立绘区、选项按钮 |
| 功能UI | 背包、商店、合成/强化界面 |

### 每个UI需提取

| 字段 | 说明 |
|-----|-----|
| UI名称 | 界面的名称 |
| 类型 | 战斗UI / 菜单UI / 对话UI / 功能UI |
| 打开条件 | 如何触发显示 |
| 关闭条件 | 如何关闭 |
| 元素清单 | 包含的按钮、文本、图标等 |
| 交互逻辑 | 用户操作流程 |
| 特殊需求 | 动画、过渡效果等 |

### 从游戏概览提取UI信息

- **对话系统**: 立绘尺寸、文本框规格、站位规则
- **操作说明**: 需要显示的快捷键提示
- **经济系统**: 货币显示位置和格式
- **核心玩法**: 需要的HUD元素

## 音频信息提取

### BGM需求
- 场景对应关系
- 情绪/风格要求
- 是否需要循环
- 参考曲目（如有）

### 音效需求
- 角色相关（脚步、语音、受击等）
- 环境音效（风声、水声等）
- UI音效
- 特殊事件音效

## 代码需求提取

根据游戏类型和设定，识别需要的系统：

| 系统类型 | 常见需求 |
|---------|---------|
| 核心玩法 | 移动、战斗、对话、探索 |
| UI系统 | 菜单、HUD、对话框 |
| 存档系统 | 存档位、自动存档 |
| 场景管理 | 场景切换、过渡动画 |
| 音频系统 | BGM切换、音效播放 |
| 资源管理 | 预加载、内存管理 |
