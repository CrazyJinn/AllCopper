# 分镜设计

将剧本中的**过场动画**转换为分镜提示词，支持动作关键帧分解。

## 输入

| 文件 | 必需 | 说明 |
|-----|-----|-----|
| 第N幕.md | **是** | 剧本第N幕的详细分场文件 |

> ⚠️ 必须提供具体的剧本幕文件（如`第一幕.md`），若无则需用户明确指定。

## 输出

```
输出目录/
├── 第一幕/
│   ├── 场景2_抵达.md      # 过场动画分镜
│   ├── 场景4_偷袭.md      # CG过场分镜
│   └── ...
├── 第二幕/
│   └── ...
└── ...
```

> 按幕建立目录，每个过场动画独立文件。若文件已存在则更新内容。

## 工作流程

1. **确认输入** - 必须有剧本第N幕文件，否则询问用户
2. **筛选过场动画** - 只处理标记为`【短动画】`、`【CG过场】`的场景
3. **拆分镜头** - 按场景和动作划分
4. **关键帧分解** - 将动作描述分解为开始帧、过程帧、结束帧
5. **生成提示词** - 组合运镜、主体、动作
6. **按幕输出** - 为每一幕创建目录，每个过场独立文件

## 处理范围

### ✅ 需要分镜设计

| 场景类型 | 剧本标记 | 说明 |
|---------|---------|------|
| 短动画 | `【短动画】` | 游戏内实时渲染的过场 |
| CG过场 | `【CG过场】` | 预制CG动画 |
| 蒙太奇 | `【蒙太奇】` | 时间流逝的快速剪辑 |

### ❌ 不需要分镜设计

| 场景类型 | 剧本标记 | 说明 |
|---------|---------|------|
| 立绘对话 | `【立绘对话】` | 静态立绘+文字 |
| 场景对话 | `【场景对话】` | 战斗中旁白 |
| 战斗 | `【战斗】` | 游戏关卡 |
| 探索 | `【自由探索】` | 玩家控制 |

## 分镜格式

```markdown
# 场景X: 场景名称

**类型**: 短动画 | CG过场
**时长**: X秒
**地点**: 场景描述

---

## 分镜提示词

镜头1 [X秒] 镜头类型。主体+运动+环境+运镜/切镜+美学描述+声音。

镜头2 [X秒] 镜头类型。主体+运动+环境+运镜/切镜+美学描述+声音。

...

---

## 关键帧分解

### 镜头1
- 开始帧: 初始状态描述
- 过程帧: 动作变化（可选）
- 结束帧: 最终状态描述

### 镜头2
...
```

## 提示词结构

### 基础公式
```
主体 + 运动 + 环境（非必须） + 运镜/切镜（非必须） + 美学描述（非必须） + 声音（非必须）
```

### 完整示例

```
镜头1 [3秒] 正面中景。普通卧室内，夜晚，窗外城市微光透进来。成年男子正对镜头站在床边，穿着普通T恤与牛仔裤，环境非常日常、安静。男子皱眉看向自己的双手，空气中开始出现细微的能量粒子，房间灯光轻微闪烁一次。

镜头2 [2秒] 切镜到手部特写。蓝白色能量迅速包裹双手，像液态金属与光能混合，从指尖向手臂流动。

镜头3 [2秒] 切镜男子面部特写。能量沿着颈部与下颌攀升，皮肤表面浮现出清晰的英雄装甲纹路，眼睛亮起冷白色光。

镜头4 [4秒] 切镜到正面中远景。能量在全身爆发，衣物被光能吞没并重构，完整的超级英雄战衣在身体表面快速成型：金属质感装甲、流线型设计、胸口能量徽章清晰点亮。他说道：
"Guess there's no going back."
```

### 要素说明

| 要素 | 说明 | 示例 |
|-----|------|-----|
| 主体 | 画面焦点 | 成年男子、女主角、教会骑士 |
| 运动 | 动作与变化 | 皱眉看向双手、能量包裹、向农场走去 |
| 环境 | 场景描述 | 普通卧室内夜晚、废土荒漠黄昏 |
| 运镜/切镜 | 镜头运动 | 切镜、镜头推进、镜头环绕 |
| 美学描述 | 视觉风格 | 逆光剪影、金属质感、冷白色光 |
| 声音 | 音效与对白 | 爆炸声、他说道"..."、旁白 |

> 通过描述对白内容、语言类型、情绪变化、镜头运动与叙事结构等内容，可以让模型生成的音频与画面更加贴合，满足专业创作场景对音画一致性的高要求。

## 关键帧分解规则

### 识别需要分解的动作

剧本中的斜体动作描述需要分解：
```
*她双手凝聚起紫色的光芒，周围的空气因魔力而扭曲。*
```

### 分解为关键帧

| 帧类型 | 描述重点 |
|-------|---------|
| 开始帧 | 动作起始状态，角色姿态 |
| 过程帧 | 动作进行中的变化（可选） |
| 结束帧 | 动作完成状态，最大张力点 |

### 示例分解

**剧本动作**:
```
*她双手凝聚起紫色的光芒，周围的空气因魔力而扭曲。*
```

**关键帧分解**:
```
- 开始帧: 她双手平举于胸前，掌心相对，表情专注
- 过程帧: 紫色光芒从掌心涌现，逐渐增强，空气开始扭曲
- 结束帧: 双手间凝聚成完整的紫色光球，周围空气剧烈扭曲，发丝飘动
```

## 提示词结构

### 基础公式
```
运镜 + 镜头类型 + 主体 + 动作 + 背景 + 氛围
```

### 示例
```
固定镜头中景，魔法主角站在战场中央，双手间凝聚紫色光球，周围空气扭曲，硝烟弥漫的战场背景，逆光剪影效果
```

## 运镜词典

详见 [shot-dictionary.md](references/shot-dictionary.md)

## 注意事项

1. **不描述角色外貌** - 角色外观由角色设计图确定，提示词只用角色名
2. **关键帧聚焦动作** - 描述动作和形态变化，不重复外貌
3. **保持连贯性** - 相邻镜头的动作要衔接
4. **提示词简洁** - 每个提示词控制在50字以内
