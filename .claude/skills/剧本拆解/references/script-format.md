# 剧本格式指南

## 电影式剧本结构

```markdown
# 剧本名称

## 第一幕

---

### 1. 场景名称

**时间/地点**

场景描述：环境、氛围、关键细节。

---

**角色名**
（动作/表情）对话内容。

**角色名**
对话内容。

---

### 2. 下一个场景
...
```

---

## 基本元素

### 场景标题
```
### 场景序号. 场景名称

**镜头类型**
**时间/地点**
```

### 镜头类型（必需）

每个场景必须标注镜头类型：

| 类型 | 标记 | 说明 |
|-----|------|------|
| **立绘对话** | `【立绘对话】` | 显示角色立绘+文字框，暂停游戏，点击继续 |
| **过场动画** | `【过场动画】` | 预制动画片段（短动画/CG），不可交互 |
| **场景对话** | `【场景对话】` | 战斗/探索中的NPC旁白，不暂停游戏，不影响操作 |

```
### 1. 接任务

【立绘对话】
**内景 秘术协会·任务大厅 - 白天**

### 2. 抵达

【过场动画】
**外景 7号农场 - 黄昏**

### 3. 战斗

【场景对话】
**外景 7号农场 - 黄昏**
```

### 时间/地点

时间/地点示例：
- **内景 营地帐篷 - 黎明**
- **外景 废弃工厂 - 白天**
- **回忆·战场 - 黄昏**

### 场景描述
```
破旧的帐篷内，篝火的余烬散发着微弱的光。晨光透过缝隙照进来，空气中弥漫着潮湿的气息。
```

### 对话
```
**角色名**
对话内容。

**角色名**
（动作/表情）带动作或表情的对话。
```

### 动作描述
```
*她猛然睁开眼睛，胸口剧烈起伏。*

*他递过一块干硬的面包，眼神中带着关切。*
```

### 旁白/画外音
```
**（旁白）**
边境地带，硝烟弥漫。
```

### 转场
```
【切至】
【淡出】
【闪回】
【回到现在】
```

---

## 分支选项

仅在需要时使用：

```
【选择】
> 提示文本

- 选择A → 跳转场景
- 选择B → 跳转场景
```

## 完整示例

---

### 1. 噩梦·战场

【过场动画】
**回忆·战场 - 黄昏**

硝烟弥漫的战场，远处不时传来爆炸声。两个身影在废墟间激烈交战。

**魔法主角**
（专注，双手凝聚紫色光芒）还没结束！

*她向教会人员冲去，掌心的火球越发明亮。*

**教会人员**
（狞笑）秘术协会的妖女！

*他举起权杖，金色的屏障在身前展开。*

**魔法主角**
让开！

*火球呼啸而出。*

*教会人员侧身挥动权杖，火球偏离轨迹，飞向远方的天际。*

**（旁白）**
火球消失在暮色中，没人知道它将落在哪里。

【切至】

---

### 2. 噩梦·废墟

【过场动画】
**回忆·聚集地 - 黄昏**

一座小型聚集地，原本平静的生活区此刻已成废墟。一具具尸体倒在血泊中。

*一个小男孩跪在两具尸体旁，肩膀颤抖。*

**小男孩**
（哭泣）爸爸...妈妈...醒醒...

*魔法主角从远处跑来，脚步在看到眼前的景象时僵住了。*

**魔法主角**
（瞳孔震颤）这...这是我...

*她认出了被自己火球击中的痕迹。*

**魔法主角**
（声音颤抖）不是...不是我...

*小男孩抬起头，泪水中混杂着仇恨。*

*魔法主角后退一步，双手止不住地颤抖。*

【淡出】

---

### 3. 惊醒

【立绘对话】
**内景 营地帐篷 - 黎明**

破旧的帐篷内，篝火的余烬散发着微弱的光。

*魔法主角猛然睁开眼睛，胸口剧烈起伏。*

**魔法主角**
（喘息）...

*她坐起身，用手背擦去额头的冷汗。*

**魔法主角**
（低声）又是那个梦...

*她闭上眼睛，深呼吸平复情绪。*

**魔法主角**
已经十五年了。

*远处传来同伴的声音。*

**同伴**（画外）
嘿，醒了吗？来吃点东西！

【切至】

---

### 4. 营地早晨

【立绘对话】
**外景 营地 - 黎明**

小型露营地，篝火已经熄灭，只剩下灰烬。东方的天空泛起鱼肚白。

*魔法主角走出帐篷，同伴正在整理装备。*

**同伴**
脸色不太好，做噩梦了？

**魔法主角**
老毛病。

*同伴递过一块干硬的面包。*

**同伴**
吃点东西。今天有任务。

**魔法主角**
（接过面包）什么任务？

**同伴**
前面那座废弃工厂，据说里面有旧时代的物资。

*魔法主角咬了一口面包，望向远方的工厂轮廓。*

**魔法主角**
听起来有风险。

**同伴**
是有点。不过值得一看。

【选择】
> 如何回应？

- **询问更多情报** → 场景5a
- **直接答应** → 场景5b

## 编写要点

1. **对话自然** - 符合角色性格，避免书面化
2. **动作辅助** - 用动作传达情绪，减少纯对话
3. **场景简洁** - 只描述关键细节，让读者想象空间
4. **节奏控制** - 动作场景用短句，情感场景放慢
5. **留白** - 不必事事交代，给玩家想象空间
