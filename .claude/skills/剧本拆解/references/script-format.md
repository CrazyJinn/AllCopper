# 剧本格式指南

## 输出文件结构

```markdown
# 剧本

## 目录
- [第一章 章节名](#第一章-章节名)
  - [场景1-1](#场景1-1)
  - [场景1-2](#场景1-2)
- [第二章 章节名](#第二章-章节名)
  - ...

---

## 第一章 章节名

### 场景1-1

**场景ID**: scene_XXX
**出场角色**: char_001, npc_001

#### 场景描述
[环境、时间、氛围描述]

#### 剧情内容

**[角色名]**: 对话内容
*[动作描述]*

**[角色名]**: 对话内容

---

### 场景1-2

...
```

## 对话格式

### 基本对话
```
**[角色ID/名称]**: 对话内容
```

### 带动作的对话
```
**[角色ID]**: 对话内容
*[动作描述]*
```

### 带表情的对话
```
**[角色ID]**: （表情）对话内容
```

### 内心独白
```
**[角色ID]**: （内心）独白内容
```

### 旁白/系统提示
```
**[系统]**: 系统提示内容
```

## 分支选项格式

```markdown
#### 选择分支

> [玩家需要做出选择]

**选项A**: [选项内容]
- → 跳转到场景X

**选项B**: [选项内容]
- → 跳转到场景Y
```

## 场景类型

| 类型 | 说明 | 示例 |
|-----|------|------|
| 过场 | 璀璨剧情，无交互 | 动画演出 |
| 对话 | 角色对话、选择分支 | NPC交互 |
| 战斗 | 进入战斗场景 | 副本入口 |
| 探索 | 自由探索区域 | 安全区、野外 |

## 注意事项

- **角色ID一致性**: 使用角色需求.md中定义的ID
- **场景ID一致性**: 使用场景需求.md中定义的ID
- **对话风格**: 符合角色性格设定
- **节奏控制**: 对话不宜过长，适合游戏节奏
