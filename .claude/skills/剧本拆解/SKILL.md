# 剧本拆解

将剧本大纲转化为可直接用于开发的详细分场剧本。

## 输入

| 文件 | 必需 | 说明 |
|-----|-----|-----|
| 剧本大纲.md | 是 | 剧情的概要、章节划分、主要情节 |
| 游戏基本信息.md | 推荐 | 提供世界观、角色信息 |
| 角色需求.md | 推荐 | 提供角色ID、性格、说话风格 |

## 输出

```
输出目录/
├── 剧本大纲.md      # 各幕内容概览
├── 第一幕.md
├── 第二幕.md
├── 第三幕.md
└── ...
```

> 按幕拆分为独立文件，便于并行开发和版本管理。若文件已存在则更新内容。
>
> `剧本大纲.md` 为提纲性文件，简要描述每一幕的核心内容、场景数量、主要角色等。

## 工作流程

1. **读取输入** - 剧本大纲、游戏信息、角色需求
2. **分析大纲** - 识别幕的划分、场景边界、角色出场、情绪转折
3. **生成提纲** - 创建/更新`剧本大纲.md`，概括各幕核心内容
4. **拆解分场** - 将概要展开为详细对话和动作
5. **按幕输出** - 为每一幕创建/更新独立文件（第一幕.md、第二幕.md...）

## 核心原则

### 镜头类型（必需）

每个场景必须标注镜头类型：

| 类型 | 标记 | 说明 |
|-----|------|------|
| **立绘对话** | `【立绘对话】` | 显示角色立绘+文字框，暂停游戏，点击继续 |
| **过场动画** | `【过场动画】` | 预制动画片段（短动画/CG），不可交互 |
| **场景对话** | `【场景对话】` | 战斗/探索中的NPC旁白，不暂停游戏，不影响操作 |

### 对话编写
- 每句对话控制在20字以内（适合游戏阅读）
- 体现角色性格和说话风格
- 避免信息倾泻，通过动作和环境传达信息

### 场景划分
- 一个场景 = 一个地点 + 一段连续剧情
- 场景切换：地点变化、时间跳跃、情绪转折

### 节奏控制
- 过场动画：紧凑有力，每段3-5句旁白
- 对话场景：给玩家选择权，2-3轮对话后给选项
- 战斗前：简短铺垫，快速进入战斗

## 格式规范

详见 [script-format.md](references/script-format.md)

## 调用方式

```
使用 剧本拆解 skill
输入目录: <包含大纲和需求文档的目录>
输出目录: <剧本输出目录>
场景范围: <可选，指定幕或场景，如"第一幕"或"第一幕·场景3-5">
```

## 文件命名规则

| 内容 | 文件名 | 说明 |
|-----|-------|------|
| 剧本提纲 | 剧本大纲.md | 各幕内容概览、场景数量、主要角色 |
| 第一幕 | 第一幕.md | 详细分场剧本 |
| 第二幕 | 第二幕.md | 详细分场剧本 |
| 第N幕 | 第N幕.md | 详细分场剧本 |

> 若文件已存在，则更新内容；若不存在，则创建新文件。

## 剧本大纲格式

```markdown
# 剧本大纲

## 第一幕
- **时间**：十五年前 / 十五年后
- **核心事件**：简要描述
- **场景数**：N个
- **主要角色**：角色A、角色B
- **内容概要**：2-3句话概括本幕内容

## 第二幕
...
```
