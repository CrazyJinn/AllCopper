# 剧本拆解

将剧本大纲转化为可直接用于开发的详细分场剧本。

## 输入

| 文件 | 必需 | 说明 |
|-----|-----|-----|
| 剧本大纲.md | 是 | 剧情的概要、章节划分、主要情节 |
| 游戏基本信息.md | 推荐 | 提供世界观、角色信息 |
| 角色需求.md | 推荐 | 提供角色ID、性格、说话风格 |

## 输出

```
输出目录/
├── 剧本大纲.md          # 各幕内容概览
├── 第一幕.md
├── 第二幕.md
├── 第三幕.md
├── ...
├── 角色立绘表情需求.md   # 汇总各角色在剧本中出现的表情
└── 立绘提示词/           # 各角色的立绘提示词
    ├── char_001_罗兰.md
    ├── char_002_薇.md
    └── ...
```

> 按幕拆分为独立文件，便于并行开发和版本管理。若文件已存在则更新内容。
>
> `剧本大纲.md` 为提纲性文件，简要描述每一幕的核心内容、场景数量、主要角色等。
>
> `角色立绘表情需求.md` 汇总剧本中各角色实际出现的表情，用于指导立绘生成。
>
> `立绘提示词/` 目录包含各角色的立绘提示词文件，基于角色设计图进行图生图。

## 工作流程

1. **读取输入** - 剧本大纲、游戏信息、角色需求
2. **分析大纲** - 识别幕的划分、场景边界、角色出场、情绪转折
3. **生成提纲** - 创建/更新`剧本大纲.md`，概括各幕核心内容
4. **拆解分场** - 将概要展开为详细对话和动作
5. **按幕输出** - 为每一幕创建/更新独立文件（第一幕.md、第二幕.md...）
6. **提取表情需求** - 汇总各角色在剧本中出现的表情，输出到`角色立绘表情需求.md`
7. **生成立绘提示词** - 基于表情需求和角色性格，为每个角色生成`立绘提示词.md`

## 核心原则

### 镜头类型（必需）

每个场景必须标注镜头类型：

| 类型 | 标记 | 说明 |
|-----|------|------|
| **立绘对话** | `【立绘对话】` | 显示角色立绘+文字框，暂停游戏，点击继续 |
| **过场动画** | `【过场动画】` | 预制动画片段（短动画/CG），不可交互 |
| **场景对话** | `【场景对话】` | 战斗/探索中的NPC旁白，不暂停游戏，不影响操作 |

### 对话编写
- 每句对话控制在20字以内（适合游戏阅读）
- 体现角色性格和说话风格
- 避免信息倾泻，通过动作和环境传达信息

### 场景划分
- 一个场景 = 一个地点 + 一段连续剧情
- 场景切换：地点变化、时间跳跃、情绪转折

### 节奏控制
- 过场动画：紧凑有力，每段3-5句旁白
- 对话场景：给玩家选择权，2-3轮对话后给选项
- 战斗前：简短铺垫，快速进入战斗

## 角色立绘表情需求格式

```markdown
# 角色立绘表情需求

> 从剧本中提取各角色实际出现的表情，用于指导立绘生成。

---

## 罗兰 (char_001)

| 表情 | 出现场景 | 优先级 |
|-----|---------|:------:|
| 平静 | 场景1.3, 场景2.1 | 必需 |
| 愤怒 | 场景1.5 | 必需 |
| 沮丧 | 场景2.4 | 必需 |

---

## 薇 (char_002)

| 表情 | 出现场景 | 优先级 |
|-----|---------|:------:|
| 平静 | 场景1.1, 场景3.2 | 必需 |
| 微笑 | 场景2.3 | 必需 |
| 沮丧 | 场景1.2 | 必需 |
| 暴怒 | 场景4.1 | 必需 |

...
```

### 表情分类

| 类别 | 表情 | 说明 |
|-----|------|------|
| 基础 | 平静、微笑 | 几乎所有角色都需要 |
| 情绪 | 大笑、愤怒、暴怒、沮丧 | 根据剧情需要 |
| 状态 | 思索、冷漠 | 根据角色性格 |

### 提取规则

1. **扫描所有对话**：识别每个角色在对话中标注的表情/动作
2. **去重合并**：同一表情只记录一次，列出所有出现场景
3. **标注优先级**：核心角色必需表情标记为"必需"，次要表情标记优先级

...

## 立绘提示词格式

立绘提示词用于生成对话立绘（表情变化），基于角色设计图进行图生图。

### 核心原则

- **不描述**：角色外观、服装、配色、艺术风格等（这些在设计图中已有）
- **只描述**：表情变化、配合表情的身体姿态、手部动作、面对镜头的角度、整体氛围
- **基于性格**：根据角色性格特征定制表情/姿态的具体表现

### 五维描述结构

| 维度 | 说明 |
|-----|------|
| 表情 | 眉眼、嘴角的细微变化 |
| 姿态 | 身体朝向、重心、站姿 |
| 手势 | 手臂、手掌、手指的动作 |
| 角度 | 角色面对镜头的方向 |
| 氛围 | 整体气质、情绪感染力 |

### 文件格式

详见 [template-立绘提示词.md](references/template-立绘提示词.md)

### 示例结构

```markdown
# 罗兰 立绘提示词

## 角色性格
- **坚毅冷静**：经历末世磨练，不易外露情绪
- **内心热血**：对保护他人有强烈责任感
- **性格表现**：即使是微笑也很克制，愤怒时眼神会变得锐利

## 立绘表情

### 平静
- **用途**：普通对话
- **角度**：正面面对镜头
- **提示词**：面容平静，眼神坚定但不凌厉，嘴角自然放松，身体站姿挺拔但不过于僵硬，双手自然垂于身体两侧，手指微微弯曲，整体透出沉稳可靠的气质，全身像，纯白背景
- **负面提示词**：背景，场景，模糊，低质量，变形

### 愤怒
- **用途**：面对敌人或背叛
- **角度**：正面面对镜头，身体微微前倾
- **提示词**：眉头紧锁，眼神锐利如刀，瞳孔微缩，面部肌肉紧绷，嘴角紧抿成一条线，身体微微前倾，重心前移呈进攻姿态，双手握拳垂于身体两侧，拳头微微颤抖，周身散发出压抑的怒意和危险的气息，全身像，纯白背景
- **负面提示词**：背景，场景，模糊，低质量，变形

...
```

> **长度要求**：每个提示词至少6个分句，约80-120字
