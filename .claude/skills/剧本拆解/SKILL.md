# 剧本拆解

将剧本大纲转化为详细的分场剧本。

## 输入

| 文件 | 必需 | 说明 |
|-----|-----|-----|
| 剧本大纲.md | 是 | 剧情的概要、章节划分、主要情节 |
| 游戏基本信息.md | 否 | 提供世界观、角色信息 |
| 角色需求.md | 否 | 提供角色ID、性格、说话风格 |

## 输出

生成 **剧本.md** 到指定目录，包含：

```
输出目录/
└── 剧本.md
```

## 剧本结构

每个场景包含：

- **场景ID**: 对应场景需求.md中的场景
- **出场角色**: 角色ID列表
- **场景描述**: 环境、氛围
- **对话内容**: 角色对话，- **动作描述**: 角色动作
- **分支选项**: 如有选择分支

## 巋作流程

1. 读取剧本大纲.md
2. 读取游戏基本信息.md（如有）
3. 读取角色需求.md（如有）
4. 将大纲拆解为详细分场
5. 输出剧本.md

## 调用方式

```
使用 script-breakdown skill
输入目录: <包含大纲和需求文档的目录>
输出目录: <剧本输出目录>
```
