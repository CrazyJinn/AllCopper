## 游戏概览

### 基本信息

| 属性 | 描述 |
|------|------|
| 类型 | 2D 俯视角动作游戏 |
| 引擎 | cocos |
| 美术风格 | 人物：手绘风格 / 地图：油画风格 |
| 核心玩法 | 搜索物资 → 战斗 → 强化角色 → 推进剧情 |

### 场景结构

```
大地图
├── 各组织城镇（安全区）
├── 废土
├── 变异森林
├── 城市废墟
└── 灰雪地（核冬天）
```

**副本系统**

**副本房间结构**

```
入口 → [普通房] → [普通房] → [精英房] → [普通房] → [Boss房] → 通关
                      ↓
                 [隐藏房]（可选，需特殊条件触发）
```

| 房间类型 | 描述 |
|----------|------|
| **普通房** | 随机普通怪物群，清空后开启通往下一房间的门 |
| **精英房** | 固定出现精英怪，击杀必掉落稀有物品 |
| **Boss房** | 最终Boss战，击杀后副本通关 |
| **隐藏房** | 需特定条件触发（如：无伤通关前几房间），内含宝箱或隐藏Boss |

### 操作说明

| 按键 | 功能 |
|:----:|------|
| `W` `A` `S` `D` | 移动 |
| `空格` | 翻滚闪避 |
| `左键` | 普通攻击 / 射击 |
| `右键` | 终极技能 |
| `Q` | 技能 1 |
| `E` | 技能 2 |
| `R` | 换弹 / 冥想（法师恢复魔法） |
| `F` | 拾取物品 |

> 鼠标指向即为目标，左右键对目标执行操作。

## 世界观

核战之后，世界支离破碎。幸存的人类分化为两大阵营：

| 阵营 | 特征 |
|------|------|
| **科技派** | 依赖科技与机械力量 |
| **魔法派** | 身体变异，可释放魔法 |

**冲突根源**：资源匮乏，两大阵营为争夺生存资源而持续争斗。

## 经济系统

### 货币体系

- **通用货币**：小口径手枪子弹
- **背景设定**：大口径子弹（战斗用）仍有生产线制造，但小口径子弹已无法生产，成为稀缺货币

### 经济循环

```
┌─────────────────────────────────────────────────┐
│                    经济循环                       │
├─────────────────────────────────────────────────┤
│                                                 │
│   完成任务 ──→ 获得货币                       │
│       │                                         │
│       ↓                                         │
│   击杀怪物 ──→ 获得怪物精粹 ──→ 商人兑换货币       │
│       │                                         │
│       ↓                                         │
│   击杀人形敌人 ──→ 直接获得货币                   │
│       │                                         │
│       ↓                                         │
│   货币 ──→ 购买物品/装备/服务                     │
│                                                 │
└─────────────────────────────────────────────────┘
```

## 势力阵营

### 科技派

| 组织 | 设计主题 | 作战风格 |
|------|:--------:|----------|
| **金属合唱团** | 深红 | 远程枪械攻击 |
| **骑士团** | 黑白灰 | 外骨骼机甲，近战为主 |
| **机械风暴** | 待定 | 召唤机器人/无人机作战 |

### 魔法派

| 组织 | 设计主题 | 作战风格 |
|------|:--------:|----------|
| **教廷** | 金色/白色 | 祷告强化自身，近战为主 |
| **秘术协会** | 紫色 | 释放杀伤性魔法，远程为主 |
| **灵魂行者** | 银色/黑色 | 召唤兽作战 |

## 角色设定

### 科技主角

| 属性 | 描述 |
|------|------|
| **性别** | 男 |
| **年龄** | 17岁 |
| **隶属** | 骑士团 |
| **外观** | 少年体型，骑士团黑白灰配色服装，轻型外骨骼装备 |
| **背景** | 3岁时双亲被女主误杀，仅存片段记忆。被骑士团救下并抚养长大。 |
| **作战风格** | 近战为主，外骨骼机甲辅助 |

### 魔法主角

| 属性 | 描述 |
|------|------|
| **性别** | 女 |
| **年龄** | 120岁（外表年轻，因变异寿命可达300岁） |
| **隶属** | 秘术协会 |
| **外观** | 银色长发，红瞳，紫色主题长袍（有魔法符文刺绣），长靴，黑丝 |
| **背景** | 14年前任务中误杀科技主角双亲，背负着这段过往。 |
| **作战风格** | 远程魔法攻击，释放杀伤性魔法 |

│    │  (GIF)   │                    │  (GIF)   │    │
│    │          │                    │          │    │
│    │ 400×800  │                    │ 400×800  │    │
│    │          │                    │          │    │
│    └──────────┘                    └──────────┘    │
│                                                     │
├─────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────┐ │
│  │  [头像]  角色名称                              │ │
│  │                                               │ │

### 尺寸规格

| 元素 | 尺寸 |
|------|------|
| 角色立绘区域 | 400px × 800px |
| 文字框高度 | 约200px |

### 角色站位

| 阵营 | 位置 |
|------|------|
| 科技派 | 屏幕左侧 |
| 魔法派 | 屏幕右侧 |

### 表情GIF系统

每句对话根据剧情切换不同表情GIF：

| 表情 | 用途 |
|------|------|
| 默认/待机 | 普通对话 |
| 微笑 | 积极情绪 |
| 生气 | 冲突、愤怒 |
| 悲伤 | 低落情绪 |
| 惊讶 | 突发情况 |
| 严肃 | 正经话题 |
| 恐惧 | 危险情况 |

**GIF规格**：400×800px，12-24FPS，透明背景

### 过场动画

对话中可触发MP4过场动画：

| 触发时机 | 行为 |
|----------|------|
| 对话前 | 先播放过场 |
| 对话中 | 暂停对话→播放过场→继续对话 |
| 对话后 | 对话结束后播放 |

**MP4规格**：1920×1080 或 1280×720，30/60FPS
