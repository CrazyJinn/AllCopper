## 规则

代码修改永远先在 `04_code/` 中进行，测试完毕后等待用户确认才同步到 `89_game/`。

**Why:** 保持代码质量和可控性，避免未测试的代码直接进入游戏项目。

**How to apply:**
1. 所有代码修改首先在 `04_code/` 中完成
2. 修改完成后提示用户运行测试 (`npm test`)
3. 测试通过后，**不要自动同步**，等待用户明确确认
4. 用户确认后，将代码复制到 `89_game/AllCooper/assets/scripts/`
