# 导演 Skill

将剧情文字拆解为分镜提示词，用于AI视频或动画生成。

## 输入

- 剧情文字描述
- 场景总时长（秒）

## 输出

- 分镜提示词列表
- 每个镜头的详细描述
- 每个镜头的开始和结束时间

## 提示词结构

### 基础结构

```
主体 / 背景 / 镜头 + 动作
```

### 多镜头连贯叙事

```
镜头1 + 主体 + 动作1 + 镜头2 + 主体 + 动作2 ...
```

### 多个连续动作

**时序性连续动作：**
```
主体1 + 运动1 + 运动2
```

**多主体不同动作：**
```
主体1 + 运动1 + 主体2 + 运动2
```

参考 `references/shot-dictionary.md`

## 工作流程

### 1. 分析剧情

- 识别场景和角色
- 提取关键动作和事件
- 确定情绪基调

### 2. 拆分镜头

- 按场景切换划分镜头
- 按动作变化划分镜头
- 确定镜头数量

### 3. 生成提示词

- 选择合适的运镜方式
- 添加程度副词增强表现力
- 组合成完整提示词

### 4. 分配时间

- 根据镜头重要性分配时长
- 确保各镜头时间之和等于总时长
- 关键动作/情绪镜头适当延长

### 5. 输出格式

每个镜头单独一行，格式为：

```
镜头X,持续Y秒-[运镜方式+画面描述]
```

## 使用示例

**输入：**
```
场景总时长：10秒
剧情：科技主角站在废墟中央，回忆起童年时父母被杀的场景，眼中含泪，紧握拳头。
```

**输出：**
```
镜头1,持续3秒-固定镜头全景，科技主角站在废墟中央，镜头静止不动
镜头2,持续4秒-面部特写缓缓拉近，科技主角眼中含泪，悲伤表情
镜头3,持续3秒-特写快速切换，拳头紧握微微颤抖
```

## 注意事项

1. **不描述人物外貌**：角色外貌由上传的人物设计图确定，提示词中只用角色名称
2. 镜头数量适中，避免过于细碎
3. 运镜方式服务于叙事，不喧宾夺主
4. 程度副词根据情绪强度选择
5. 保持镜头间的连贯性
