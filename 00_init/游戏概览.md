## 角色美术资源

游戏角色需要三种美术资源，各有不同用途和规格。不同角色类型的资源需求不同。

### 资源类型

#### 设计图

| 属性 | 描述 |
|------|------|
| 用途 | 角色基础设计，立绘和精灵图的参考基准 |
| 风格 | 手绘动漫风格 |
| 内容 | 全身像 |

#### 立绘

| 属性 | 描述 |
|------|------|
| 用途 | 对话系统 |
| 尺寸 | 400×800px |
| 格式 | PNG，纯白背景 |

**规则**：
- 基于同一角色设计图，通过图生图方式生成变体
- 立绘可能有多种变体，根据剧情需要来生成

#### 精灵图

| 属性 | 描述 |
|------|------|
| 用途 | 游戏内角色动画 |
| 风格 | Q版（2-3头身） |
| 格式 | PNG，纯白背景 |
| 方向 | 只有正面和背面两种，左右方向通过翻转实现 |

---

### 按角色类型的资源需求

| 角色类型 | 设计图 | 立绘 | 精灵图（完整） | 精灵图（简化） |
|---------|:------:|:----:|:-------------:|:-------------:|
| 主角 | ✅ | ✅ | ✅ | - |
| NPC（重要） | ✅ | ✅ | - | ✅ |
| NPC（次要） | ✅ | ✅ | - | ✅ |
| 怪物 | ✅ | ❌ | ✅ | - |

**精灵图需求说明**：
- **完整精灵图**：待机、移动、攻击、受击、死亡
- **简化精灵图**：待机、移动

## 场景结构

### 大地图与场景

大地图和场景是两个独立层级，各司其职：

**大地图**：全局导航界面。以图标/节点展示世界各区域，玩家点对点选择目的地后进入对应场景。大地图上不可自由移动角色，不是可游玩空间。

**场景**：从大地图进入的具体地点，是实际可游玩/可交互的空间。所有场景共用同一套角色移动和战斗系统。

**区域**：大地图上的地理位置划分（废土、变异森林、城市废墟、灰雪地等），每个区域包含若干战斗场景和功能场景，随剧情发展逐步开放。

```
区域（大地图上的地理划分）
├── 战斗场景（随剧情逐步开放）
│   └── 多房间推进结构
└── 功能场景（各势力控制的安全区）
    └── NPC对话 / 商店 / 休息 / 任务领取
```

### 场景分类

| 类型 | 定位 | 功能 |
|------|------|------|
| **战斗场景** | 战斗 | 多房间推进，击杀怪物、搜集物资、Boss战 |
| **功能场景** | 功能 | NPC对话、商店交易、休息恢复、任务领取 |

### 过场

过场不是一种场景类型，而是一组按顺序自动播放的静态图片序列，穿插在场景之间或场景内部用于叙事。

| 属性 | 描述 |
|------|------|
| 组成 | 一组按顺序排列的静态图片，自动逐张播放 |
| 图片规格 | 1920×1080px，PNG格式，按顺序编号 |
| 触发时机 | 进入场景前 / 场景内对话中 / 离开场景后 |
| 作用 | 叙事过渡、关键剧情展示、氛围营造 |

**生成流程**：
1. 根据剧情分镜拆分出N张过场画面
2. 为每张画面生成独立提示词
3. 批量生成图片
4. 在引擎中按编号顺序编排自动播放

### 战斗场景类型

每个战斗场景对应一种核心玩法，包含多个子房间：

| 战斗场景类型 | 核心玩法 | 特殊机制 |
|---------|---------|---------|
| **教学战斗场景** | 新手引导 | 逐步解锁功能 |
| **防守战斗场景** | 魔物rush | 波次防守、大量敌人 |
| **潜入战斗场景** | 潜入探索 | 视角受限、警戒系统 |
| **收集战斗场景** | 战斗爽 | 击杀收集资源 |
| **解谜战斗场景** | 推进剧情 | 解谜元素、偏女主 |
| **对话战斗场景** | 剧情对话 | 纯对话推进 |

### 战斗场景房间结构

```
入口 → [普通房] → [普通房] → [精英房] → [普通房] → [Boss房] → 通关
                      ↓
                 [隐藏房]（可选，需特殊条件触发）
```

| 房间类型 | 描述 |
|----------|------|
| **普通房** | 随机普通怪物群，清空后开启通往下一房间的门 |
| **精英房** | 固定出现精英怪，击杀必掉落稀有物品 |
| **Boss房** | 最终Boss战，击杀后战斗场景通关 |
| **隐藏房** | 需特定条件触发（如：无伤通关前几房间），内含宝箱或隐藏Boss |

### 游戏场景生成流程

**战斗场景房间采用摆件拆分生成**：

| 步骤 | 操作 | 输出 |
|------|------|------|
| 1 | 分析场景需要的摆件元素 | 摆件清单 |
| 2 | 为每个摆件生成独立提示词 | 提示词列表 |
| 3 | 批量生成摆件图片 | PNG透明背景图片 |
| 4 | 在游戏引擎中组合摆放 | 预制体 |

**摆件分类**：

| 类别 | 尺寸范围 | 示例 |
|------|---------|------|
| 地面Tile | 128×128 / 256×256 | 石板、裂纹地、积水 |
| 墙体 | 按需 | 石墙、木墙、门框 |
| 大型摆件 | 256×256 ~ 512×512 | 柱子、火把架、武器架 |
| 小型摆件 | 64×64 ~ 128×128 | 补给箱、骨头堆、碎石 |
| 光源 | 64×64 ~ 128×128 | 火把、蜡烛、发光水晶 |

## 伤害机制

### 伤害分配规则

```
受到伤害时：
├── X% → 扣除护盾（由角色属性决定）
└── Y% → 扣除HP（100% - X%）
```

> 伤害分配比例是**动态属性**，不同角色/装备有不同的护盾吸收率

### 护盾恢复

- 护盾在未受伤害时**缓慢自动恢复**
- 恢复速度由角色属性决定

### 特殊伤害类型

| 伤害类型 | 效果 |
|---------|------|
| **普通伤害** | X%护盾/（100% - X%）%HP分配 |
| **中毒伤害** | 直接扣除HP，无视护盾 |
| **碎盾伤害** | 扣除巨额护盾，不扣HP |

### 角色受伤模式

| 触发条件 | 描述 |
|---------|------|
| 碰撞怪物身体 | 与怪物实体碰撞 |
| 碰撞怪物攻击 | 被怪物攻击判定命中 |

- **翻滚闪避时无敌**：闪避动作期间免疫所有伤害

### 怪物受伤模式

| 触发条件 | 描述 |
|---------|------|
| 碰撞角色攻击 | 被角色攻击判定命中 |

## 文献收集系统

薇的核心动机是还原战前历史，对应一套贯穿全流程的文献碎片收集玩法。

### 文献碎片

散落在世界各处的战前记录残片，每片记载一小段战前信息。玩家收集后可在文献界面中查看已拼凑的内容。

**文献类型**：

| 类型 | 内容 | 稀有度 |
|------|------|--------|
| **报纸残页** | 战前新闻报道，反映战前社会状态 | 常见 |
| **日记残页** | 普通人的战前生活记录 | 常见 |
| **科研报告** | 战前科技研究的片段 | 稀有 |
| **军事指令** | 战前军队的作战命令或通信 | 稀有 |
| **政府档案** | 战前政府的决策文件 | 极稀有 |

### 获取途径

| 来源 | 说明 |
|------|------|
| 战斗场景隐藏房 | 固定掉落一篇文献碎片 |
| 剧情关卡 | 部分关卡通关奖励 |
| 商人购买 | 花费纽扣电池购买，稀有文献价格昂贵 |
| 废墟探索 | 大地图中特定废墟地点可拾取 |
| 敌人掉落 | 教会精英敌人有概率掉落被截获的文献 |

### 文献界面

独立界面，按时间线排列已收集的文献碎片，逐步还原战前历史全貌。

- 未收集的文献显示为模糊的空位，提示可能获取的地点或方式
- 文献按时间段分类，同一时期的碎片拼凑后可解锁一段完整叙事
- 集齐某个时期的全部文献后，解锁对应的额外剧情（薇的回忆/感悟）

### 与主线的关联

- 文献内容逐步揭示教会"科技导致毁灭"叙事的矛盾之处，支撑薇追寻真相的动机
- 部分关键文献直接推动剧情发展（如揭示某个遗迹的位置、以诺的真实身份线索）
- 罗兰线也可获取文献，但视角不同——他看到的是战前普通人如何生活，而非历史真相

## 操作说明

### 移动与战斗

| 按键 | 功能 |
|:----:|------|
| `W` `A` `S` `D` | 移动 |
| `空格` | 翻滚闪避 |

| `右键` | 终极技能 |

| `R` | 换弹（科技）/ 加快技能CD（魔法） |

| 按键 | 功能 |
|:----:|------|
| `1` | 快捷栏位 1（消耗品/道具） |
| `2` | 快捷栏位 2（消耗品/道具） |
| `3` | 快捷栏位 3（消耗品/道具） |
| `4` | 快捷栏位 4（消耗品/道具） |

> 快捷栏可放置药水、投掷物、食物等可消耗物品，在背包界面拖拽配置。

| 按键 | 功能 |
|:----:|------|
| `I` / `B` | 打开/关闭背包 |

> 鼠标指向即为目标，左右键对目标执行操作。

## 经济系统

### 货币体系

- **通用货币**：纽扣电池
- **单位**：满电为1
- **背景设定**：电力是末世最稀缺的资源

```
┌─────────────────────────────────────────────────┐
│                    经济循环                       │

│                                                 │

│       │                                         │

│   纽扣电池 ──→ 购买物品/装备/服务                 │

```

## 对话系统

### 两种布局模式

#### 模式一：对话布局（角色分列两边）

用于角色之间的对话场景。

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│    ┌──────────┐                    ┌──────────┐    │
│    │          │                    │          │    │
│    │  角色A   │                    │  角色B   │    │
│    │  (PNG)   │                    │  (PNG)   │    │
│    │          │                    │          │    │
│    │ 400×800  │                    │ 400×800  │    │
│    │          │                    │          │    │
│    └──────────┘                    └──────────┘    │
│                                                     │
├─────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────┐ │
│  │  [头像]  角色名称                              │ │
│  │                                               │ │
│  │  对话文本内容...                              │ │
│  │                              [点击继续 ▼]     │ │
│  └───────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

#### 模式二：独白布局（角色居中）

用于角色内心独白场景。

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│                    ┌──────────┐                    │
│                    │          │                    │
│                    │  角色    │                    │
│                    │  (PNG)   │                    │
│                    │          │                    │
│                    │ 400×800  │                    │
│                    │          │                    │
│                    └──────────┘                    │
│                                                     │
├─────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────┐ │
│  │  [头像]  角色名称（或省略）                     │ │
│  │                                               │ │
│  │  内心独白内容...                              │ │
│  │                              [点击继续 ▼]     │ │
│  └───────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

### 尺寸规格

| 元素 | 尺寸 |
|------|------|
| 角色立绘区域 | 400px × 800px |
| 文字框高度 | 约200px |

### 角色站位（对话模式）

先说话的角色立绘占据左侧，后说话的角色立绘占据右侧

### 表情立绘系统

每句对话根据剧情切换不同表情立绘（PNG格式）：

| 表情 | 用途 |
|------|------|
| 平静 | 普通对话 |
| 微笑 | 积极情绪 |
| 大笑 | 开心、兴奋 |
| 愤怒 | 不满、生气 |
| 暴怒 | 极度愤怒 |
| 沮丧 | 低落情绪 |
| 思索 | 思考、犹豫 |
| 冷漠 | 无情、冷淡 |

**立绘规格**：400×800px，PNG格式，纯白背景

### 过场

对话中可触发过场（自动播放的图片序列，详见"场景结构 → 过场"）：

| 触发时机 | 行为 |
|----------|------|
| 对话前 | 先播放过场，再开始对话 |
| 对话中 | 暂停对话→播放过场→继续对话 |
| 对话后 | 对话结束后播放 |
