├── 废土
├── 变异森林
├── 城市废墟
└── 灰雪地（核冬天）
```

### 副本系统

**副本房间结构**

```
入口 → [普通房] → [普通房] → [精英房] → [普通房] → [Boss房] → 通关
                      ↓
                 [隐藏房]（可选，需特殊条件触发）
```

| 房间类型 | 描述 |
|----------|------|
| **普通房** | 随机普通怪物群，清空后开启通往下一房间的门 |
| **精英房** | 固定出现精英怪，击杀必掉落稀有物品 |
| **Boss房** | 最终Boss战，击杀后副本通关 |
| **隐藏房** | 需特定条件触发（如：无伤通关前几房间），内含宝箱或隐藏Boss |

## 操作说明

| 按键 | 功能 |
|:----:|------|
| `W` `A` `S` `D` | 移动 |
| `空格` | 翻滚闪避 |
| `左键` | 普通攻击 / 射击 |
| `右键` | 终极技能 |
| `Q` | 技能 1 |
| `E` | 技能 2 |
| `R` | 换弹 / 冥想（法师恢复魔法） |
| `F` | 拾取物品 |

> 鼠标指向即为目标，左右键对目标执行操作。

## 经济系统

### 货币体系

- **通用货币**：纽扣电池
- **单位**：满电为1
- **背景设定**：电力是末世最稀缺的资源

```

│    │          │                    │          │    │
│    └──────────┘                    └──────────┘    │
│                                                     │

### 尺寸规格

| 元素 | 尺寸 |
|------|------|
| 角色立绘区域 | 400px × 800px |
| 文字框高度 | 约200px |

### 角色站位

| 阵营 | 位置 |
|------|------|
| 科技派 | 屏幕左侧 |
| 魔法派 | 屏幕右侧 |

### 表情GIF系统

每句对话根据剧情切换不同表情GIF：

| 表情 | 用途 |
|------|------|
| 默认/待机 | 普通对话 |
| 微笑 | 积极情绪 |
| 生气 | 冲突、愤怒 |
| 悲伤 | 低落情绪 |
| 惊讶 | 突发情况 |
| 严肃 | 正经话题 |
| 恐惧 | 危险情况 |

**GIF规格**：400×800px，12-24FPS，透明背景

### 过场动画

对话中可触发MP4过场动画：

| 触发时机 | 行为 |
|----------|------|
| 对话前 | 先播放过场 |
| 对话中 | 暂停对话→播放过场→继续对话 |
| 对话后 | 对话结束后播放 |

**MP4规格**：1920×1080 或 1280×720，30/60FPS
