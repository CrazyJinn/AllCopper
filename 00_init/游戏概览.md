## 角色美术资源

游戏角色需要三种美术资源，各有不同用途和规格。不同角色类型的资源需求不同。

### 资源类型

#### 设计图

| 属性 | 描述 |
|------|------|
| 用途 | 角色基础设计，立绘和精灵图的参考基准 |
| 风格 | 手绘动漫风格 |
| 内容 | 全身像 |

#### 立绘

| 属性 | 描述 |
|------|------|
| 用途 | 对话系统 |
| 尺寸 | 400×800px |
| 格式 | PNG，透明背景 |

**必需表情**：默认、微笑、悲伤、愤怒、惊讶、严肃、恐惧

#### 精灵图

| 属性 | 描述 |
|------|------|
| 用途 | 游戏内角色动画 |
| 风格 | Q版（2-3头身） |
| 格式 | PNG，透明背景 |
| 方向 | 只有正面和背面两种，左右方向通过翻转实现 |

---

### 按角色类型的资源需求

| 角色类型 | 设计图 | 立绘 | 精灵图（完整） | 精灵图（简化） |
|---------|:------:|:----:|:-------------:|:-------------:|
| 主角 | ✅ | ✅ | ✅ | - |
| NPC（重要） | ✅ | ✅ | - | ✅ |
| NPC（次要） | ✅ | ✅ | - | ✅ |
| 怪物 | ✅ | ❌ | ✅ | - |

**精灵图需求说明**：
- **完整精灵图**：待机、行走、奔跑、攻击、受击、死亡、交互等全套动画
- **简化精灵图**：待机、行走、交互（无攻击、受击、死亡）

## 场景结构

```
大地图
├── 各组织城镇（安全区）
├── 废土
├── 变异森林
├── 城市废墟
└── 灰雪地（核冬天）
```

### 副本系统

**副本房间结构**

```
入口 → [普通房] → [普通房] → [精英房] → [普通房] → [Boss房] → 通关
                      ↓
                 [隐藏房]（可选，需特殊条件触发）
```

| 房间类型 | 描述 |
|----------|------|
| **普通房** | 随机普通怪物群，清空后开启通往下一房间的门 |
| **精英房** | 固定出现精英怪，击杀必掉落稀有物品 |
| **Boss房** | 最终Boss战，击杀后副本通关 |
| **隐藏房** | 需特定条件触发（如：无伤通关前几房间），内含宝箱或隐藏Boss |

## 战斗资源系统

### 角色资源

| 资源类型 | 描述 |
|---------|------|
| **HP** | 生命值，归零则角色死亡 |
| **护盾** | 优先于HP承受伤害，缓慢恢复 |
| **子弹** | 远程武器弹药，近战角色无此资源 |
| **技能CD** | 终极技能冷却时间 |
| **普攻CD** | 普通攻击冷却时间 |

### 怪物资源

| 资源类型 | 描述 |
|---------|------|
| **HP** | 生命值，归零则怪物死亡 |
| **护盾** | 优先于HP承受伤害，缓慢恢复 |
| **技能CD** | 特殊技能冷却时间 |
| **普攻CD** | 普通攻击冷却时间 |

## 伤害机制

### 伤害分配规则

```
受到伤害时：
├── X% → 扣除护盾（由角色属性决定）
└── Y% → 扣除HP（100% - X%）
```

> 伤害分配比例是**动态属性**，不同角色/装备有不同的护盾吸收率

### 护盾恢复

- 护盾在未受伤害时**缓慢自动恢复**
- 恢复速度由角色属性决定

### 特殊伤害类型

| 伤害类型 | 效果 |
|---------|------|
| **普通伤害** | 90%护盾/10%HP分配 |
| **中毒伤害** | 直接扣除HP，无视护盾 |
| **碎盾伤害** | 扣除巨额护盾，不扣HP |

## 受伤判定

### 角色受伤模式

| 触发条件 | 描述 |
|---------|------|
| 碰撞怪物身体 | 与怪物实体碰撞 |
| 碰撞怪物攻击 | 被怪物攻击判定命中 |

### 闪避机制

- **翻滚闪避时无敌**：闪避动作期间免疫所有伤害

### 怪物受伤模式

| 触发条件 | 描述 |
|---------|------|
| 碰撞角色攻击 | 被角色攻击判定命中 |

## 背包系统

类似暗黑2的背包容量系统。

### 背包容量

- 每个角色有固定的**背包大小**
- 每个物品占用一定的**空间大小**
- 物品放入背包需检查剩余容量

### 机甲角色加成

| 角色类型 | 背包加成 |
|---------|---------|
| 穿机甲角色 | 天生背包容量更大 |
| 普通角色 | 标准背包容量 |

## 阵营玩法差异

| 阵营 | 核心玩法 | 描述 |
|------|---------|------|
| **科技阵营** | 搜打撤 | 强调资源搜集、战斗、撤离的循环 |

## 操作说明

### 移动与战斗

| 按键 | 功能 |
|:----:|------|
| `W` `A` `S` `D` | 移动 |
| `空格` | 翻滚闪避 |
| `左键` | 普通攻击 / 射击 |
| `右键` | 终极技能 |
| `Q` | 技能 1 |
| `E` | 技能 2 |
| `R` | 换弹 / 冥想（法师恢复魔法） |
| `F` | 拾取物品 |

### 物品快捷栏

| 按键 | 功能 |
|:----:|------|
| `1` | 快捷栏位 1（消耗品/道具） |
| `2` | 快捷栏位 2（消耗品/道具） |
| `3` | 快捷栏位 3（消耗品/道具） |
| `4` | 快捷栏位 4（消耗品/道具） |

> 快捷栏可放置药水、投掷物、食物等可消耗物品，在背包界面拖拽配置。

### 界面操作

| 按键 | 功能 |
|:----:|------|
| `I` / `B` | 打开/关闭背包 |
| `M` | 打开/关闭地图 |
| `Tab` | 切换小地图显示模式 |
| `Esc` | 暂停菜单 / 关闭界面 |
| `C` | 角色属性面板 |

> 鼠标指向即为目标，左右键对目标执行操作。

## 经济系统

### 货币体系

- **通用货币**：纽扣电池
- **单位**：满电为1
- **背景设定**：电力是末世最稀缺的资源

### 经济循环

```
┌─────────────────────────────────────────────────┐
│                    经济循环                       │
├─────────────────────────────────────────────────┤
│                                                 │
│   完成任务 ──→ 获得纽扣电池                     │
│       │                                         │
│       ↓                                         │
│   击杀怪物 ──→ 获得怪物精粹 ──→ 商人兑换电池       │
│       │                                         │
│       ↓                                         │
│   击杀人形敌人 ──→ 直接获得纽扣电池               │
│       │                                         │
│       ↓                                         │
│   纽扣电池 ──→ 购买物品/装备/服务                 │
│                                                 │
└─────────────────────────────────────────────────┘
```

```
│    ┌──────────┐                    ┌──────────┐    │
│    │          │                    │          │    │
│    │  角色A   │                    │  角色B   │    │
│    │  (GIF)   │                    │  (GIF)   │    │
│    │          │                    │          │    │
│    │ 400×800  │                    │ 400×800  │    │
│    │          │                    │          │    │
│    └──────────┘                    └──────────┘    │
│                                                     │
├─────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────┐ │
│  │  [头像]  角色名称                              │ │
│  │                                               │ │
│  │  对话文本内容...                              │ │

```

### 尺寸规格

| 元素 | 尺寸 |
|------|------|
| 角色立绘区域 | 400px × 800px |
| 文字框高度 | 约200px |

### 角色站位

| 阵营 | 位置 |
|------|------|
| 科技派 | 屏幕左侧 |
| 魔法派 | 屏幕右侧 |

### 表情GIF系统

每句对话根据剧情切换不同表情GIF：

| 表情 | 用途 |
|------|------|
| 默认/待机 | 普通对话 |
| 微笑 | 积极情绪 |
| 生气 | 冲突、愤怒 |
| 悲伤 | 低落情绪 |
| 惊讶 | 突发情况 |
| 严肃 | 正经话题 |
| 恐惧 | 危险情况 |

**GIF规格**：400×800px，12-24FPS，透明背景

### 过场动画

对话中可触发MP4过场动画：

| 触发时机 | 行为 |
|----------|------|
| 对话前 | 先播放过场 |
| 对话中 | 暂停对话→播放过场→继续对话 |
| 对话后 | 对话结束后播放 |

**MP4规格**：1920×1080 或 1280×720，30/60FPS
